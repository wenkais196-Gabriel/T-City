工作平板 demo v1 · 全职业可用 / 职业专属软件

手机是随手看一眼，平板是坐下来干活。同一套后端，换一个壳、换一套布局。

谁能用全职业。平板本身不挑人，软件挑人 怎么挑服务端按 job 下发 app 清单，不在清单里的根本不渲染 手机关系手机 App 保留（随身查看），平板是同一批 App 的大屏形态 不改的业务逻辑。警察终端仍是 police_mdt 那套 appAction

这一版 demo 的重点

  1. 职业切换 — 右上角切警察 / 机械师 / EMS，首页软件跟着变
  2. 三列 MDT — 警情列表 / 详情+操作 / 单位与动态，一屏看全
  3. 申领即出发 — 点「前往」自动给路线，开到现场自动记到场（3 秒后模拟）
  4. 清场才归档 — 选 disposition，生成案号，进案件库

为什么不是把手机放大

手机 375×780 是竖屏单列，警情板、单位、记录只能一条条往下堆。 平板 1060×660 是横屏三列：左手选单、中间处置、右手看谁在路上—— 这三个信息在手机上是互斥的，在平板上是并存的。

还没决定的

平板怎么掏出来（随身物品 / 警车中控 / 家里工作台）、哪些职业先做专属软件、 是否需要「同一账号同时只开一台」——这些看完 demo 再定。
