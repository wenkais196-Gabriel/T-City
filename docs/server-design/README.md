## 设计原则速查

```
预设内容 → 把玩家推进涌现式系统 → 产生互赖关系 → 产生所有权感
                                                      ↓
                                          Patron 月供 ← → Identity 消费
                                          （养这地方）     （我的成就得让人看见）
```

**四大工程锚点**：
- **世界痕迹** — "我上次下线前做的事，这次上线还能看到后果"
- **不可替代性** — "这个服务器上有些事，非我不可"
- **规则参与** — "这个世界的规则，我有发言权"
- **叙事所有权** — "这个服务器有自己的故事，我的行为是故事的一部分"

**付费铁律**：
- ✅ 卖美观（绑成就的 cosmetic）
- ✅ 卖便利（不扭曲核心玩法）
- ✅ 卖身份（Patron 养服务器）
- ❌ 不卖游戏货币
- ❌ 不卖数值优势
- ❌ 不卖执法豁免

```
P2 (Phase 3 深度集成):
  → 预设→涌现任务漏斗
  → 共治投票系统
  → 赛季编年史
```
