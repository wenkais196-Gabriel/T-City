# 真机验证清单（按模块）

> 给 PO 在游戏里逐项过。每一项都是「操作 → 期望」，末尾一句写「没通过说明什么」。
> 命令都已核对存在（`docs/client/ux/admin-commands.md` 是同一次扫描生成的）。
>
> 记号：**[单]** 一个账号即可；**[双]** 需要第二个客户端 / 第二个账号。
> 造状态几乎都用管理员命令；先把账号设成管理员：控制台 `add_principal player.<id> qbcore.admin`
> （需要 god 的项写 `qbcore.god`）。
