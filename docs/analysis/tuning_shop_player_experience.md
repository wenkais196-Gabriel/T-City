# T-City2 改装店玩家体验流程设计

> **日期**: 2026-06-05 | **版本**: v1.0 | **状态**: 设计草案  
> **前序文档**: `tuning_shop_analysis.md` — 项目现状审计 + 社区调研

---

## 1. 设计原则

```
改装不是"点菜单→付钱→秒装完"的廉价体验，而是：
  玩家设计 → 技师评估 → 预约排期 → 备料施工 → 交付验收 → 后续服务
             六阶段完整 RP 闭环
```

| 原则 | 说明 |
|:---|:---|
| **预览免费、施工收费** | 玩家在预览菜单随心设计，0成本探索，只有提交订单后才涉及经济 |
| **技师是必要中介** | 改装必须由在线技师施工，玩家不可自助改装（维修除外） |
| **等级=能力边界** | 技师等级决定可施工的改装范围，预览时透明标注 |
| **预约=时间成本** | 复杂改装需要预约档期，期间技师需要备料 |
| **物料=经济循环** | 零件/漆料/工具需要提前准备，连接采矿→冶炼→零件供应链 |
| **中控屏=交付物延伸** | NOS/霓虹灯/底盘灯等特殊改装，安装后在车载中控屏出现控制开关 |

## 3. 各阶段详细设计

### 3.1 阶段① — 自助预览终端 (Player Self-Service Preview)

**触发**: 玩家驾驶自有车辆进入改装店，走向 Customs Marker

**UI 设计**: 全屏 NUI，模仿 GTA Online 改装菜单布局：
- 左侧: 车辆 3D 预览（可旋转/缩放）
- 右侧: 改装类别树形菜单
- 底部: 当前累计报价

```
┌──────────────────────────────────┬──────────────────────┐
│                                  │  ▲ 外观改装          │
│                                  │  ├─ Spoiler      Lv2 │
│     [车辆 3D 实时预览]            │  ├─ Front Bumper Lv3 │
│     可拖拽旋转/滚轮缩放           │  ├─ Side Skirt   Lv1 │
│     每选一个改装即时渲染           │  ├─ Exhaust      Lv4 │
│                                  │  ┊                    │
│                                  │  ▲ 性能改装          │
│                                  │  ├─ Engine       Lv3 │
│                                  │  ├─ Brakes       Lv2 │
│                                  │  ├─ Turbo        Lv1 │
│                                  │  ┊                    │
│                                  │  ▲ 喷漆              │
│                                  │  ├─ Primary  #FF0000 │
│                                  │  └─ Secondary #000000│
│                                  │  ▲ 特殊改装          │
│                                  │  ├─ Nitrous    🔒大师│
│                                  │  ├─ Neon Kit   🔒宗师│
│                                  │  └─ ECU Tune   🔒宗师│
├──────────────────────────────────┴──────────────────────┤
│  预报价: $48,500  │  [保存方案] [提交订单] [放弃离开]    │
└─────────────────────────────────────────────────────────┘
```

**关键规则**:

| 规则 | 说明 |
|:---|:---|
| **仅限自有车辆** | 非自有车辆进入预览终端提示"你不是该车辆的所有者" |
| **实时预览** | 每选一个零件，车辆模型立即更新（SetVehicleMod 本地预览） |
| **兼容性过滤** | 菜单只显示该车型支持的改装（GetNumVehicleMods 过滤） |
| **等级标注** | 需要技师等级的改装标注 🔒大师 / 🔒宗师 / 🔒传奇，灰色不可选 |
| **预报价** | 系统自动计算：零件费 + 基础工时费，不含技师调整 |
| **方案存取** | 玩家可保存最多 5 套方案，下次直接加载 |

**预报价公式**:
```
preQuote = Σ(每个改装项)
每个改装项 = partBasePrice × shopMultiplier
partBasePrice: 零件基准价 (config 表定义)
shopMultiplier: 店铺倍率 (合法店 1.0, Benny's 1.5, 地下店 2.0)
```

|:---|:---|
| **等级过滤** | 技师等级不够的改装项自动标红剔除，不可接 |

### 3.3 阶段③ — 技师备料 (Mechanic Material Preparation)

**触发**: 技师确认接单、玩家确认报价后，订单进入 `preparing` 状态

**备料清单自动生成**:

```lua
-- 系统根据改装项自动生成物料清单
{
    orderId = "TUN-20260605-0042",
    materials = {
        { item = "veh_engine",      qty = 1, source = "craft|order|inventory" },
        { item = "veh_turbo",       qty = 1, source = "craft|order|inventory" },
        { item = "veh_exterior",    qty = 2, source = "craft|order|inventory" },
        { item = "paint_metallic",  qty = 1, source = "craft|order|inventory" },
        { item = "steel_plate",     qty = 4, source = "mining→smelt" },
    },
    tools = { "wrench", "torque_wrench", "spray_gun" }
}
```

**物料来源**:

```
采矿 (custom-mining)
  ↓ 原矿
冶炼 (custom-mining 冶炼炉)
  ↓ iron_ingot / copper_ingot / steel_plate 等
零件制作 (Workbench Marker)
  ↓ veh_engine / veh_brakes / veh_turbo 等
改装店库存 (Storage Marker)
  ↓ 技师从库存取用
```

**关键规则**:

| 规则 | 说明 |
|:---|:---|
| **库存检查** | 接单时自动检查店铺库存，不足的标黄提示 |
| **零件订购** | 技师可通过 Laptop Marker 向供应商订购零件（扣除店铺资金，延迟送达） |
| **玩家自备料** | 玩家可以自己提供零件（从背包/后备箱），降低改装费用 |
| **备料完成通知** | 备料OK后，系统通知玩家"可以送车了" |
| **超时惩罚** | 技师备料超时（超过档期24h），订单自动取消，技师扣信用分 |

### 3.4 阶段④ — 施工安装 (Installation Workflow)

**触发**: 玩家按档期送车到店，技师在 Tuning Bay 开始施工

**施工 UI — 步骤化工作流**:

```
┌──────────────────────────────────────────┐
│  🔧 正在施工: Elegy RH8 | #TUN-...-0042   │
│                                           │
│  ┌─ 施工清单 ──────────────────────────┐  │
│  │ ✅ 1. 车辆上架举升机                │  │
│  │ ✅ 2. 安装 Spoiler Lv2   -1 veh_ext │  │
│  │ ⏳ 3. 安装 Front Bumper  -1 veh_ext │  │ ← 当前步骤
│  │ ⬜ 4. 安装 Engine Lv3     -1 veh_eng│  │
│  │ ⬜ 5. 安装 Turbo Lv1      -1 veh_tur│  │
│  │ ⬜ 6. 喷漆 Primary       -1 paint_m │  │
│  │ ⬜ 7. 车辆下架交付                  │  │
│  └──────────────────────────────────────┘  │
│                                           │
│  ████████████░░░░░░  60%  当前: 安装Bumper│
│                                           │
│  物料消耗: veh_exterior ×1 (库存剩余: 3)   │
└──────────────────────────────────────────┘
```

**每步施工 = 动画 + 进度条 + 粒子特效**:
- 性能件: 打开引擎盖 → 拆卸旧件 → 安装新件 → 扭力扳手上紧 → 关闭引擎盖
- 外观件: 对准位置 → 螺丝固定 → 调整缝隙
- 喷漆: 遮蔽胶带 → 打磨旧漆 → 调色 → 喷涂（颜色渐变过渡）→ 清漆 → 烘烤
- 特殊件: NOS — 后备箱走管路 → 气瓶固定 → 电磁阀接线 → 中控屏配对

**关键规则**:

| 规则 | 说明 |
|:---|:---|
| **不可中断** | 单个改装步骤不可中断，但步骤之间技师可以暂停 |
| **物料实时扣** | 每步开始即消耗对应物料，失败不退 |
| **施工质量** | 技师施工有小概率"失误"（minigame 失败），需重新施工 |
| **客户可见进度** | 玩家可在店外看到实时进度条（可选是否进入施工区观看） |
| **特殊改装激活中控屏** | NOS/霓虹灯/底盘灯/ECU调校 安装后自动在 tcity-dashboard 中激活对应控制面板 |

## 4. 维修分流设计

### 4.1 自助维修站 (Self-Service Repair Station)

```
玩家开车到维修站 → 交互 → 检测报告 → 选择维修项目 → 消耗物料 → 进度条 → 完成
```

| 规则 | 值 |
|:---|:---|
| **最高修复度** | 80% 引擎健康 / 80% 车体健康 |
| **可修项目** | 引擎健康、轮胎、车窗、基础车体 |
| **不可修** | 磨损部件（radiator/axle/brakes/clutch）、严重变形 |
| **物料消耗** | 与技师维修相同（repairkit / advancedrepairkit） |
| **耗时** | 30秒（技师维修可更快，20秒） |
| **费用** | 无工时费，仅物料消耗 |

### 4.2 技师维修 (Mechanic Repair)

```
玩家到改装店 → 技师接车 → 检测 → 报价 → 施工 → 付款取车
```

| 规则 | 值 |
|:---|:---|
| **最高修复度** | 100% 全部健康 |
| **可修项目** | 全部：引擎/车体/磨损部件/变形/车窗/轮胎 |
| **物料消耗** | 与自助相同 |
| **额外费用** | 工时费（技师自定义） |
| **额外服务** | 洗车、打蜡、四轮定位等增值项目 |

### 4.3 维修对比

| 维度 | 自助维修站 | 技师维修 |
|:---|:---|:---|
| 引擎修复上限 | 80% | 100% |
| 磨损部件 | ❌ | ✅ |
| 工时费 | $0 | 技师自定义 |
| 等待时间 | 30s | 视技师效率 |
| RP 深度 | 低（纯功能性） | 高（互动+检测+施工） |
| 适用场景 | 应急/省钱 | 全面保养/高性能要求 |

## 5. 特殊改装的 Dashboard 集成

### 5.1 改装 → 中控屏映射

| 改装类型 | Dashboard 激活的模块 |
|:---|:---|
| **NOS 氮气** | 氮气控制面板：开关/喷射力度/剩余量/温度监控 |
| **霓虹灯套件** | 灯光控制面板：开关/颜色/闪烁模式（跟随音乐/呼吸灯/常亮） |
| **底盘灯** | 灯光控制面板：同上 |
| **ECU 调校** | 性能调校面板：预设模式切换（经济/运动/赛道）/ 自定义参数 |
| **防滚架** | 安全面板：显示"赛道模式已激活" |
| **宽体套件** | 车身面板：显示宽体套件安装状态 |
| **引擎更换** | 性能面板：新引擎型号/马力/扭矩显示 |

### 5.2 激活流程

```
技师完成改装 → server 标记 vehicle_state.modInstallFlags
  → { nos: true, neon: true, ecu: 'stage2', ... }
  → 玩家上车 → client dashboard 读取 modInstallFlags
  → 动态渲染新增控制面板
  → 面板右上角显示 "🔧 LS Customs 安装"
```

## 6. 订单状态机

```
                    ┌──────────┐
                    │  draft   │  玩家在预览终端保存草稿
                    └────┬─────┘
                         │ 玩家提交
                         ▼
                    ┌──────────┐
                    │ pending  │  等待技师接单
                    └────┬─────┘
                         │ 技师接受
                         ▼
                    ┌──────────┐
              ┌─────│ accepted │  技师调整报价+设定档期
              │     └─────┬────┘
              │           │ 玩家确认
              │           ▼
              │     ┌───────────┐
              │     │ preparing │  技师备料中
              │     └─────┬─────┘
              │           │ 备料完成+玩家送车
              │           ▼
              │     ┌────────────┐
              │     │ in_progress│  施工中
              │     └─────┬──────┘
              │           │ 施工完成
              │           ▼
              │     ┌───────────┐
              │     │ completed │  已交付
              │     └───────────┘
              │
              │     ┌──────────┐
              └─────│ rejected │  技师拒绝
                    └──────────┘
                    ┌──────────┐
                    │cancelled │  任意阶段取消
                    └──────────┘
                    ┌──────────┐
                    │ disputed │  争议中(管理员介入)
                    └──────────┘
```

## 8. 数据模型

-- 改装订单
CREATE TABLE mechanic_orders (
    id VARCHAR(32) PRIMARY KEY,          -- TUN-20260605-0042
    shop_id VARCHAR(32) NOT NULL,
    customer_citizenid VARCHAR(64) NOT NULL,
    mechanic_citizenid VARCHAR(64),
    vehicle_plate VARCHAR(16) NOT NULL,
    status ENUM('draft','pending','accepted','preparing','in_progress','completed','rejected','cancelled','disputed'),
    items JSON,                          -- 改装项目清单
    system_quote DECIMAL(12,2),          -- 系统预报价
    final_quote DECIMAL(12,2),           -- 技师最终报价
    labor_fee DECIMAL(12,2),             -- 工时费
    scheduled_at DATETIME,               -- 预约时间
    completed_at DATETIME,
    warranty_days INT DEFAULT 7,
    rating TINYINT,                      -- 玩家评分 1-5
    created_at DATETIME DEFAULT NOW()
);

-- 改装历史 (每辆车的完整改装记录)
CREATE TABLE vehicle_mod_history (
    id INT AUTO_INCREMENT PRIMARY KEY,
    vehicle_plate VARCHAR(16) NOT NULL,
    order_id VARCHAR(32),
    shop_id VARCHAR(32),
    mechanic_citizenid VARCHAR(64),
    mod_type INT,                        -- 改装类型ID
    mod_index INT,                       -- 改装等级
    part_consumed VARCHAR(64),           -- 消耗的零件物品名
    created_at DATETIME DEFAULT NOW(),
    INDEX idx_plate (vehicle_plate)
);
