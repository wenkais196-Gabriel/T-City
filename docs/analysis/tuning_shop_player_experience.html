1. 设计原则

🎯 核心理念

改装不是"点菜单→付钱→秒装完"的廉价体验，而是
玩家设计 → 技师评估 → 预约排期 → 备料施工 → 交付验收 → 后续服务
六阶段完整 RP 闭环

🆓 预览免费、施工收费
玩家在预览菜单随心设计，0成本探索，只有提交订单后才涉及经济
👨‍🔧 技师是必要中介
改装必须由在线技师施工，玩家不可自助改装（维修除外）
📊 等级=能力边界
技师等级决定可施工的改装范围，预览时透明标注
📅 预约=时间成本
复杂改装需要预约档期，期间技师需要备料
📦 物料=经济循环
零件/漆料/工具需要提前准备，连接采矿→冶炼→零件供应链
📱 中控屏=交付物延伸
NOS/霓虹灯/底盘灯等特殊改装，安装后在车载中控屏出现控制开关

3. 各阶段详细设计

3.1 阶段① — 自助预览终端

触发: 玩家驾驶自有车辆进入改装店，走向 Customs Marker

🖥️ 预览终端 UI 布局
┌──────────────────────────────────┬──────────────────────────┐ │ │ ▲ 外观改装 │ │ │ ├─ Spoiler Lv2 │ │ [车辆 3D 实时预览] │ ├─ Front Bumper Lv3 │ │ 可拖拽旋转/滚轮缩放 │ ├─ Side Skirt Lv1 │ │ 每选一个改装即时渲染 │ ├─ Exhaust Lv4 │ │ │ ┊ │ │ │ ▲ 性能改装 │ │ │ ├─ Engine Lv3 │ │ │ ├─ Brakes Lv2 │ │ │ ├─ Turbo Lv1 │ │ │ ┊ │ │ │ ▲ 特殊改装 │ │ │ ├─ Nitrous 🔒大师 │ │ │ ├─ Neon Kit 🔒宗师 │ │ │ └─ ECU Tune 🔒宗师 │ ├──────────────────────────────────┴──────────────────────────┤ │ 预报价: $48,500 │ [保存方案] [提交订单] [放弃离开] │ └─────────────────────────────────────────────────────────────┘
规则说明
仅限自有车辆非自有车辆进入预览终端提示"你不是该车辆的所有者"
实时预览每选一个零件，车辆模型立即更新（SetVehicleMod 本地预览）
兼容性过滤菜单只显示该车型支持的改装（GetNumVehicleMods 过滤）
等级标注需要技师等级的改装标注 🔒大师 🔒宗师 🔒传奇，灰色不可选
预报价系统自动计算：零件费 + 基础工时费，不含技师调整
方案存取玩家可保存最多 5 套方案，下次直接加载

预报价公式: preQuote = Σ partBasePrice × shopMultiplier

3.3 阶段③ — 技师备料

触发: 技师确认接单、玩家确认报价后，订单进入 preparing 状态

📦 物料来源链
采矿 (custom-mining) ↓ 原矿 冶炼 (custom-mining 冶炼炉) ↓ iron_ingot / copper_ingot / steel_plate 等 零件制作 (Workbench Marker) ↓ veh_engine / veh_brakes / veh_turbo 等 改装店库存 (Storage Marker) ↓ 技师从库存取用 → 施工消耗
规则说明
库存检查接单时自动检查店铺库存，不足的标黄提示
零件订购技师可通过 Laptop Marker 向供应商订购（扣除店铺资金，延迟送达）
玩家自备料玩家可以自己提供零件（从背包/后备箱），降低改装费用
备料完成通知备料OK后，系统通知玩家"可以送车了"
超时惩罚技师备料超时（>档期24h），订单自动取消，技师扣信用分

3.4 阶段④ — 施工安装

触发: 玩家按档期送车到店，技师在 Tuning Bay 开始施工

🔧 施工步骤化工作流
┌──────────────────────────────────────────┐ │ 🔧 正在施工: Elegy RH8 | #TUN-...-0042 │ │ │ │ ┌─ 施工清单 ──────────────────────────┐ │ │ │ ✅ 1. 车辆上架举升机 │ │ │ │ ✅ 2. 安装 Spoiler Lv2 -1 veh_ext│ │ │ │ ⏳ 3. 安装 Front Bumper -1 veh_ext│ │ ← 当前步骤 │ │ ⬜ 4. 安装 Engine Lv3 -1 veh_eng│ │ │ │ ⬜ 5. 安装 Turbo Lv1 -1 veh_tur│ │ │ │ ⬜ 6. 喷漆 Primary -1 paint_m│ │ │ │ ⬜ 7. 车辆下架交付 │ │ │ └──────────────────────────────────────┘ │ │ │ │ ████████████░░░░░░ 60% 当前: 安装Bumper│ │ 物料消耗: veh_exterior ×1 (库存剩余: 3) │ └──────────────────────────────────────────┘

每步施工 = 动画 + 进度条 + 粒子特效:

  • 性能件: 打开引擎盖 → 拆卸旧件 → 安装新件 → 扭力扳手上紧 → 关闭引擎盖
  • 外观件: 对准位置 → 螺丝固定 → 调整缝隙
  • 喷漆: 遮蔽胶带 → 打磨旧漆 → 调色 → 喷涂（颜色渐变过渡）→ 清漆 → 烘烤
  • NOS: 后备箱走管路 → 气瓶固定 → 电磁阀接线 → 中控屏配对
规则说明
不可中断单个改装步骤不可中断，但步骤之间技师可以暂停
物料实时扣每步开始即消耗对应物料
施工质量技师施工有小概率"失误"（minigame 失败），需重新施工
客户可见进度玩家可在店外看到实时进度条
特殊改装激活中控屏NOS/霓虹灯/底盘灯/ECU 安装后自动在 custom-vehicles dashboard 中激活控制面板

支付渠道: 现金 / 银行卡 / 店铺账户转账 / 分期付款（>$50k，3期，每期+5%手续费）

规则说明

中控屏激活安装的特殊改装自动在 dashboard 中添加控制项

玩家开车到维修站 → 交互 → 检测报告 → 选择维修项目 → 消耗物料 → 进度条 → 完成

最高修复度80%
可修项目引擎健康、轮胎、车窗、基础车体
不可修磨损部件、严重变形
物料消耗与技师维修相同
耗时30秒
费用无工时费，仅物料消耗
适用场景应急 / 省钱

T-City2 独有优势:

  • 预约档期 — 所有竞品均未实现，T-City2 首创技师设定档期+玩家按时送车
  • 等级透明化 — 预览菜单标注🔒，技师接单自动过滤，而非后台暗箱限制
  • 供应链闭环 — 采矿→冶炼→零件→改装 完整经济链路，而非孤立的制作系统
  • Dashboard 集成 — 改装后自动激活车载中控屏控制面板，交付物延伸到车内体验
  • 80/100 维修分流 — 自助应急 vs 技师全面保养，物料消耗相同但修复上限不同
  • 保修+评价 — 社区无人实现的售后体系

8. 实施路线

P0 首周 — 核心闭环

  • 预览终端 NUI（3D 车辆预览 + 类别菜单 + 预报价）
  • 技师订单 App（接单 / 报价 / 档期）
  • 施工工作流（步骤化 + 动画 + 物料消耗）
  • 交付 + 付款（economy_service 统一扣款）

P1 第二周 — 技师体系

  • 技师等级 + 经验系统
  • 等级门槛标注 + 自动过滤
  • 备料系统（库存检查 + 订购 + 制作）
  • 自助维修站（Repair Station）

P2 第三周 — Dashboard 集成

  • NOS / 霓虹灯 / ECU 激活 dashboard 面板
  • 改装历史查询 /carhistory
  • 保修 + 技师评价系统

P3 远期 — 经营系统

  • 玩家自有改装店
  • 技师招聘
  • 营收仪表盘
