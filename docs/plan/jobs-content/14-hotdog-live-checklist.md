# 热狗摊：真机验收清单（单人 / 多人分列）

> 依据 `docs/plan/jobs-content/10-hotdog-ux-spec.md`（A1–A22 / V1–V8）与
> `docs/plan/jobs-content/13-hotdog-remaining-plan.md`（剩余分片与阻塞项）。
> 本文件把「一个人就能验」和「必须两个人」分开：**前者现在就能做，后者一律 ⛔ 待后期**。

## 0. 开服前（一次性）

```bash
# 打开 dev 模板（默认不加载）
setr quest_hotdog_dev 1
refresh                      # 改了 fxmanifest 才需要
restart custom-quest         # 注意：restart 会连带停依赖，之后 exec configs/modules/quest.cfg
curl -s 127.0.0.1:30130/info.json | head -c 200
```

数值是**测试期占位**（正式值等经济系统联动，见 13 号文档 E 片）：

| 项 | 测试期值 |
|---|---|
| 押金 | $50 |
| 租金 | $1 / 分钟（前 30 秒免租，最多计 20 分钟） |
| 单价 | 普通 $8 / 稀有 $16 / 高级 $32 |
| 成品回收 | 单价 × 0.5（$4 / $8 / $16） |
| 原料回收 | $1 / 份 |
| 税 | 0（账单显示「未启用」） |
| 起始库存 | 普通 6 / 稀有 3 / 高级 1 |
| 顾客节奏 | 第一位 3–6 秒，之后 6–15 秒，耐心 30 秒 |

## 1. 单人可测（一个人 + 一个客户端）

| # | 验什么 | 怎么做 | 预期 |
|---|---|---|---|
| S1 | 租车与押金 | 走到租赁点 `215.0,-772.0,30.5` 按 E | 扣 $50 押金、推车生成、计时开始；`quest_event_log` 有 `rental_open` |
| S2 | 计租 | 站在原地 3 分钟再还车 | 租金 = 分钟数 × $1（前 30 秒免租），押金退还 = 50 − 租金 |
| S3 | 断线补退 | 租车后直接退出游戏，重连 | 登录时自动结算上一班，押金按已用时长退，日志有补退记录 |
| S4 | 摆摊三判据 | 分别试：离租赁点 > 200 m、压在路面上、贴着别人的摊位 | 三种都被拒且提示具体原因；合规位置放下成功 |
| S5 | 做热狗 | 在摊位按 G | 进小游戏；结束后库存 +1、原料 −1；品质由服务端定（客户端只报 faults） |
| S6 | 顾客上门 | 摆好后原地等 | 3–6 秒第一位顾客，之后 6–15 秒一位；报价条 30 秒走完自动消失 |
| S7 | 成交与拒绝 | Y 成交 / N 拒绝各试 3 次 | 成交：库存 −1、收入 +单价、听到收银声；拒绝：连拒 3 次进入 60 秒冷却 |
| S8 | 收摊只推进一次 | 在摊位按 E 收摊，看控制台 | **不出现** `Step order violation`；步骤只前进一格；收到「收摊了 · 本班售出 N 份」 |
| S9 | 账单六行 | 收摊后做完任务 | 售出收入 / 押金退还 / 租金 / 成品回收 / 原料回收 / 税（显示「未启用」）；净额 = 各行之和 |
| S10 | 账单幂等 | 让任务完成事件重复触发一次（重连或再进任务页） | 不会出现第二张账单；重复查看显示「已结算」 |
| S11 | 音效（单人） | 等顾客上门、成交、被拒 | 上门是世界声（旁人也能听到）；收银只有自己听到；不刺耳、不叠成一团 |
| S12 | 状态条 | 摆摊后看屏幕左下 | 显示成品三档 / 原料 / 已售 / 收入；**不挡** qb-hud 的血条与状态环（若挡，记下分辨率） |
| S13 | 摊位菜单（键盘） | 站到摊位前按 ALT 打开自己的菜单 | 六行可读、中文不是方块、`↑↓` 选择、`Enter` 买 1 份（对自己摊位是「试买」） |

## 2. 多人待测（⛔ 后期，两个客户端）

**没做之前不要算"功能完成"**——这些是买家侧唯一能证明 A8 / A10 的路径。

| # | 验什么 | 怎么做 | 预期 |
|---|---|---|---|
| M1 | 买家看见摊位 | 摊主摆好，买家走到 10 m 内 | 买家 ALT 菜单出现该摊位的可买清单与单价；离开 12 m 后菜单消失 |
| M2 | 买家购买 | 买家买 1 份普通热狗 | 买家扣款、摊主库存 −1、摊主收入 +$8；双方各听到一声收银 |
| M3 | 摊主状态不被覆盖 | 摊主站在自己摊位 10 m 内，同时买家在旁 | 摊主的「我是摊主」记录不被公开广播覆盖：状态条与按 E 收摊仍然可用 |
| M4 | 库存售罄 | 买家把普通档买空 | 该档从买家菜单里消失（不是买失败） |
| M5 | 押金与库存隔离 | 买家打开菜单时抓包 / 看日志 | 旁观者 payload 里**没有** citizenid、收入、库存明细、顾客报价 |
| M6 | 音效叠音 | 两人同时成交 | 两声收银不叠成噪音；25 m 外的第三人不被收银声打扰 |
| M7 | 顾客 ped 不挡路 | 两人在摊位附近走动 | ped 不卡住玩家、不挡车 |
| M8 | 断线重连（多人） | 摊主掉线期间买家买 | 报价/购买被拒并提示，不产生幽灵交易 |

## 3. 怎么记结果

每条填三样：**跑没跑 / 实际看到什么 / 是否与本表一致**。不一致就开 issue 或直接改代码，
不要用"应该没问题"结案（`AGENTS.md` §7：不要把"应该做"写成"已经做"）。

真机进游戏唯一可行的路径是 `tools/dev/fivem_console.py --key`（合成键）+ `adc <src> <cmd>` 直达 App；
OS 光标被 GTA 锁在屏幕角，合成鼠标点击进不了 NUI。
