## 一、世界观与势力映射

### 1.1 翻版原则

| 层级 | 原则 | 说明 |
|:---|:---|:---|
| **表层** | 不直接使用真实国名/组织名 | 所有名称T-City世界观重新包装 |
| **结构层** | 势力关系、代理人逻辑、多层嵌套 | 忠实映射中东权力结构 |
| **事件层** | 关键历史事件翻版 | 停火/撕毁/人质/抗议/外部干预 |
| **主题层** | "战争没有赢家" / "和平需要所有人同时选择" | 核心主题贯穿 |

### 1.2 五大势力板块

#### 🏛️ 板块一：The Establishment（建制派）

| T-City | 中东原型 | 核心资源 |
|:---|:---|:---|
| Los Santos 市政府 (mayor) | 以色列政府 | 立法权、预算分配 |
| LSPD (police) | IDF/以色列国防军 | 武力、情报、逮捕权 |
| 司法系统 (judge + lawyer) | 以色列司法 + 国际调解 | 合法性、审判 |
| **内部裂痕**: 强硬派 vs 改革派 | 内塔尼亚胡右翼 vs 反战抗议 | — |

**外部支持者**: "The Federation"（联邦）→ 映射美国  
→ 提供武器、资金、外交庇护  
→ 但其真正目标是维持地区不稳定以销售军火

#### 💀 板块二：The Resistance（抵抗力量）

| T-City | 中东原型 | 核心资源 |
|:---|:---|:---|
| **Cartel** (主) | 哈马斯 + 真主党 | 毒品经济、地道网络、武装力量 |
| Aztecas (辅) | 巴勒斯坦伊斯兰圣战 | 街头战士、自杀式袭击 |
| Vagos (辅) | 也门胡塞武装 | 港口劫持、海上封锁 |
| **内部裂痕**: 旧派(生意) vs 激进派(战争) | 务实派 vs 军事翼 | — |

**外部支持者**: "The Consortium"（财团）→ 映射伊朗  
→ 提供武器、情报、资金  
→ 但其真正目标是驱逐Federation势力，建立自己的霸权

#### 💼 板块三：The Neutrals（中立方）

| T-City | 中东原型 | 角色 |

## 三、三条主线大纲

### 3.1 💀 黑帮线：仇恨之链 (Chain of Hate)

> **主题**: 复仇 vs 共存，生意 vs 荣耀，旧秩序 vs 新血  
> **核心冲突**: Cartel内部旧派（El Jefe）与激进派（El Lobo）的权力斗争  
> **映射**: 哈马斯内部务实派与军事翼的张力

**章节规划**:

| 章 | 名称 | 阶段 | 核心事件 |
|:---|:---|:---|:---|
| Ch.1 | 血仇 | Phase 0→1 | Cartel高层亲属被LSPD击毙 → 复仇动员（保留现有Cartel Ch.1 "First Blood"） |
| Ch.2 | 领土 | Phase 1→2 | 与其他帮派争夺/结盟 → Aztecas入盟 → Vagos谈判 |
| Ch.3 | 围城 | Phase 2→3 | 停火期对旧派的考验 → 激进派借"停火被撕毁"夺权 |
| Ch.4 | 清算 | Phase 3→4 | 帮派内战（旧派 vs 激进派）→ 决定结局方向 |

**关键决策点**:
- D1 (Ch.1末): 复仇方式 → "精准打击"（仁慈） vs "无差别报复"（激进）
- D2 (Ch.2末): 对待战俘 → "交换/释放"（仁慈） vs "处决"（激进）
- D3 (Ch.3中): 停火期 → "遵守停火"（仁慈） vs "暗中备战"（激进）
- D4 (Ch.4初): 内部清算 → "谈判"（仁慈） vs "清洗"（激进）

> **隐藏真结局条件**: 四个决策全部选"仁慈"路径 + 成功与至少一个其他帮派达成权力共享协议

### 3.2 🛡️ 公职线：蓝墙裂痕 (Cracks in the Blue Wall)

> **主题**: 忠诚 vs 正义，秩序 vs 专制，体制内的抵抗  
> **核心冲突**: LSPD强硬派（Reyes）与改革派（Chen）的对抗  
> **映射**: 以色列内部反战运动 + 体制内自我纠错

**章节规划**:

| 章 | 名称 | 阶段 | 核心事件 |
|:---|:---|:---|:---|
| Ch.1 | 盾牌 | Phase 0→1 | 遭遇突袭 → 调查袭击来源 → 发现可疑武器来源 |
| Ch.2 | 裂隙 | Phase 1→2 | 内部对"铁壁行动"手段的分歧 → Chen开始秘密调查Federation |
| Ch.3 | 崩塌 | Phase 2→3 | 停火被撕毁后 → Reyes夺权 → Chen被边缘化 → 公开反叛 |
| Ch.4 | 审判 | Phase 3→4 | 揭露Federation阴谋 → 逮捕腐败官员 → 体制自我清算 |

**关键决策点**:
- D1 (Ch.1末): 对待被俘帮派成员 → "依法处理"（改革） vs "刑讯逼供"（强硬）
- D2 (Ch.2中): 对市民抗议 → "对话/保护"（改革） vs "武力镇压"（强硬）
- D3 (Ch.3中): 发现Federation交易证据 → "公开揭露"（改革） vs "沉默/销毁"（强硬）
- D4 (Ch.4初): 是否逮捕市长 → "依法逮捕"（改革） vs "默许/包庇"（强硬）

> **隐藏真结局条件**: 四个决策全部选"改革"路径 + 成功公开审判市长并驱逐Federation

### 3.3 🏘️ 市民线：灰烬中的声音 (Voice from the Ashes)

> **主题**: 生存 vs 抗争，沉默 vs 呐喊，个人的力量  
> **核心冲突**: 普通市民如何在战争中活下去，并最终成为改变局势的力量  
> **映射**: 巴以平民经历 + 全球公民社会的作用

**章节规划**:

| 章 | 名称 | 阶段 | 核心事件 |
|:---|:---|:---|:---|
| Ch.1 | 日常 | Phase 0 | 战争前的正常生活 → 建立人际关系网 |
| Ch.2 | 废墟 | Phase 1 | 第一次交火波及 → 失去→选择：逃离/发战争财/帮助他人 |
| Ch.3 | 觉醒 | Phase 2 | 结识关键NPC(Reporter Kael/Attorney Voss) → 发现真相碎片 |
| Ch.4 | 呐喊 | Phase 3→4 | 组织和平运动 → 收集证据 → 公开揭露 → 迫使双方谈判 |

**关键决策点**:
- D1 (Ch.2中): 面对他人受难 → "帮助"（良知） vs "自保"（生存）
- D2 (Ch.2末): 资源选择 → "分享/建社区"（合作） vs "囤积/黑市"（个人）
- D3 (Ch.3中): Reporter Kael被捕 → "冒险营救"（勇气） vs "保持沉默"（恐惧）
- D4 (Ch.4初): 收集足够证据后 → "公开揭露双方赞助者"（真相） vs "只揭露一方"（站队）

> **隐藏真结局条件**: 四个决策全部选"良知/合作/勇气/真相"路径 + 同时曝光Consortium和Federation + 和平运动影响力达到阈值

## 四、四阶段分幕叙事

### Phase 0: 战前暗涌（第1-2周）→ 故事内：2023.10之前

#### 总体状态
- 城市表面平静，暗流涌动
- Cartel巩固毒品帝国
- LSPD日常执法
- 市民正常生活

#### 三线初始状态

| 线 | 初始状态 | 起始任务 |
|:---|:---|:---|
| 黑帮 | Cartel成员。El Jefe在扩张势力 | 现有Cartel Ch.1 "First Blood" (完整保留) |
| 公职 | LSPD新人/现役。正常执法循环 | 日常巡逻 → 发现异常军火流入报告 |
| 市民 | 任意非帮派/非公职职业 | 自由生活 → 注意到物价上涨/奇怪人物出现 |

#### Phase 0 暗线事件（自动触发）

```
Day 1-3:  港口集装箱报告增多（暗示军火流入）
Day 2-4:  "外地商人"频繁出入Madrazo Ranch（Consortium特使初次接触）
Day 3-5:  LSPD总部出现"Federation顾问"——不穿LSPD制服但佩戴特殊徽章
Day 5-7:  多起"失踪案"——实际是双方都在秘密逮捕/绑架对方人员
Day 7-10: 市民注意到物价上涨、某些商品短缺
Day 10-14: 社会气氛紧张——NPC对话中会出现不安的台词
```

#### Phase 0 终 → Phase 1 触发器（GM大事件）

```
触发条件: Phase 0 持续至少10天（现实2周的游戏活跃时间）
事件名称: "THE SPARK"（火花）

LSPD特别行动组（Reyes指挥）突袭Cartel安全屋
→ Cartel高层亲属（El Jefe的弟弟）在行动中被击毙
→ LSPD官方声明："合法执法" 
→ Cartel内部：复仇呼声压倒一切
→ El Jefe面临抉择：压制激进派（失去威信）还是同意报复（走向战争）

→ 无论El Jefe如何选择，El Lobo将自行发动报复行动
→ 进入Phase 1
```

### Phase 1: 全面升级（第3-5周）→ 故事内：2023.10-2024

#### 核心事件序列

```
Week 3 初（GM大事件）: "OCTOBER SURPRISE"（十月奇袭）
  → Cartel + Aztecas联合行动
  → 同时对三处目标发动攻击：
     1. LSPD Davis分局（佯攻，牵制警力） 
     2. 市政厅（主攻，占领并劫持人质）
     3. 法官住宅区（恐吓，发射RPG/纵火）
  → 多人死伤，市长被短暂劫持后获救
  → 多名警官和政府官员被俘
  → 映射：2023.10.7 哈马斯突袭

Week 3 中-末:
  → LSPD宣布"OPERATION IRON WALL"（铁壁行动）
  → Davis/Strawberry区域戒严
  → 大规模逮捕
  → 市民线：第一次流弹伤亡事件 → 平民开始恐慌

Week 4:
  → The Federation公开声明 → 武器/资金援助LSPD
  → The Consortium秘密向Cartel输送重型武器
  → Port开始出现"意外"——货柜"丢失"、工人"罢工"
  → 第一次物资短缺（燃油/医疗用品）
  → 黑帮线：El Jefe和El Lobo的裂痕首次显现
  → 公职线：Chen第一次质疑行动合法性

Week 5:
  → 第一次Port货运劫持（Vagos参与）→ 映射：胡塞劫持红海商船
  → 全城燃油危机 → 加油站配额
  → 市民线：生存压力 → 玩家选择出路
  → 公职线：Reyes推动更强硬措施 → 与Chen对立公开化
  → 黑帮线：开始拉拢其他帮派（Ballas/Triads/Lost MC/Families）
```

#### Phase 1 终事件

```
当Port累计被劫持3次以上 + 三线各完成至少1个关键任务时
→ 触发第一次调停尝试（GM事件）
→ 由Judge Hartman + Attorney Voss 发起
→ 双方代表在"中立地点"（Vinewood酒店）会面
→ 这是第一次三方（政府+Cartel+调解人）同框
→ 结果：暂时降低交火烈度，但无正式停火
→ 进入Phase 2
```

### Phase 2: 代理人战争（第6-9周）→ 故事内：2024-2025.1

#### 核心事件序列

```
Week 6（GM大事件）: "CHOOSE YOUR SIDE"（选边站）
  → 5个非Cartel帮派必须表态：
     - Aztecas → 已与Cartel结盟（Phase 1已定）
     - Ballas → 与Cartel结盟（利益交换）
     - Vagos → 与Cartel结盟（Port合作）
     - Lost MC → 宣布中立（不参与城市战争）
     - Families → 暗中与政府合作（换保护）
     - Triads → 公开中立，私下向双方出售武器

Week 7:
  → Port危机全面升级 → 全城进入物资配给制
  → EMS/市民组织"人道走廊" → 从交火区撤离平民
  → Cartel激进派策划更大行动
  → 公职线：Chen秘密调查Federation的武器流向

Week 8:
  → 第一次正式停火谈判（GM大事件）
  → Attorney Voss主持谈判
  → 双方交换俘虏
  → 条件：Cartel停止攻击市政设施 ←→ LSPD从Davis撤出
  → 停火生效（预计持续5-7游戏日）
  → 市民线：短暂的安宁期 → 和平运动开始组织

Week 9 初:
  → 停火期间，玩家可以自由RP
  → 暗线：Federation和Consortium都不希望和平
  → Federation向Reyes施压："停火=示弱"
  → Consortium向El Lobo传递假情报："政府在停火期间秘密增兵"

Week 9 末（GM大事件）: "BROKEN PROMISE"（背弃的承诺）
  → 停火被撕毁（多种可能触发方式）：
     - 激进派发动偷袭（默认路径）
     - 政府方先动手（如果Reyes掌权）
     - 第三方挑拨（Triads制造假旗事件）
  → 无论如何 → 停火崩溃
  → 大规模冲突重燃
  → 大量平民伤亡 → 市民线转折点
  → 进入Phase 3
```

## 七、结局判定系统

### 7.1 结局判定流程

```
Phase 4 结束时 → 执行结局判定:

1. 计算三方隐藏条件完成情况：
   gangEndingReady = (gangMercyPoints >= 4) AND (至少1个其他帮派权力共享协议)
   copEndingReady = (copReformPoints >= 4) AND (市长被公开审判) AND (Federation被驱逐)
   civEndingReady = (civicCouragePoints >= 4) AND (Consortium和Federation均被曝光) AND (和平运动影响力 >= 阈值)

2. 判定：
   IF gangEndingReady AND copEndingReady AND civEndingReady THEN
       → 隐藏真结局：破局
   ELSE IF cartelFaction == "radicals" AND lspdFaction == "hardliners" AND civilianCasualties >= 极高 THEN
       → 隐藏坏结局：深渊
   ELSE
       → 默认结局：僵局（温和版 or 惨烈版取决于伤亡数和势力状态）
```

### 7.2 三个结局的叙事

#### 🟡 默认结局：僵局 (STALEMATE)

```
最终停火签署。
Cartel: El Lobo死亡/被捕 → 群龙无首 → 分裂成小帮派
LSPD: Reyes死亡/被捕 → 组织涣散
政府: 市长可能死亡/下台 → 权力真空
市民: 城市废墟中重建
Federation & Consortium: 目标达成（地区持续不稳定，军火市场继续存在）
→ 75,000映射：惨重伤亡，无人胜利

叙事主题: "战争结束了。没有人赢。"
```

#### 🟢 隐藏真结局：破局 (BREAKTHROUGH)

```
三方联合行动成功。
Cartel: El Jefe恢复权力 → 帮派获得部分合法化途径
         → 与其他帮派签署《帮派共存协议》
LSPD: Chen代理局长 → 内部改革 → Reyes被公开审判
        → Federation特使被驱逐 → 军火流入中止
政府: 市长被弹劾 → 改革派临时政府
        → 反腐败调查 → Federation交易曝光
市民: Consortium和Federation双重曝光 → 公众愤怒
        → 《新城市公约》签署 → 重建开始

额外揭示（隐藏真结局独有）:
The Merchant（地下军火商）在最终审判中作证：
"Consortium和Federation是同一枚硬币的两面。
  他们制造战争，因为战争是他们的产品。
  没有他们，今天这场战争本不会发生。"

叙事主题: "当所有人都选择停手时，战争才真正结束。"
```

#### 🔴 隐藏坏结局：深渊 (THE ABYSS)

```
Phase 3-4期间双方激进派完全掌权 + 市民完全沉默/退却。

Cartel: El Lobo完全掌权 → 恐怖统治 → 内部清洗 → 帮派内战
LSPD: Reyes完全掌权 → 军事管制 → 戒严令 → 警察国家
市民: 被完全压制 → 没有人道救援 → 没有真相记录
Federation和Consortium: 不需要再伪装 → 公开介入
→ 外部势力直接军事干预
→ 城市变成永远的战场
→ 没有停火，没有谈判，没有重建

叙事主题: "当所有人都选择沉默时，战争就会永远燃烧。"
```

- ✓ 三条弧线定义 (cartel/police/civilian)
- ✓ 分支决策点系统

需要新增：

- `server/event_scheduler.lua` — 自动事件调度器
- `server/cross_arc_handler.lua` — 交叉事件触发逻辑

### 8.2 custom-quest 扩展

现有 `custom-quest` 支持：
- ✓ 分级地址池
- ✓ 任务模板
- ✓ 随机任务生成

- 每章对应的阶段任务（Phase-locked quests）
