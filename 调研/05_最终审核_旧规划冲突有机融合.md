#### 3. 配方引擎的实现细节
`custom-cartel/server/drug_lab.lua` 的配方配置是否真正从服务端配置文件读取（而非客户端传入），未深入审计完整代码。

| quest_manager min_license 检查 | `custom-quest/server/quest_manager.lua:70-85` | ✅ 已实现 |

### ❌ 关键偏差

#### 定价未落地 — 所有证件 $150

报告中 P0 建议：
> "将免试买证价格设定为考试成本的 30 倍以上（如 $3,000 / $15,000）"

实际代码 `custom-certificates/config.lua:4-38`：

```lua
Config.CertificateTypes = {
    driver = { ..., cost = 150 },
    pilot  = { ..., cost = 150 },
    boat   = { ..., cost = 150 },
    heavy  = { ..., cost = 150 },
    weapon = { ..., cost = 150 },
}
```

**所有证件统一 $150，完全没有价格杠杆。** 这意味着：
- 考试报名费（任务配置中 ~$100）+ 领证费 ($150) = $250
- 市政厅直接买证 = $150
- 直接买反而比考试便宜！完全违背了"引导玩家体验驾考"的设计意图

#### qb-cityhall 的定价来源
`qb-cityhall/server/main.lua` 从 `Config.Cityhalls[hall].licenses[item].cost` 读取价格，需核对 cityhall 自身的 config.lua 是否也设了 $150。

### 整改建议

| ID | 措施 | 优先级 |
|:---|:---|:---|
| B2-1 | 修改 `custom-certificates/config.lua`：driver=$2000, pilot=$10000, heavy=$5000, boat=$3000, weapon=$8000 | **P0** |
| B2-2 | 同步修改 `qb-cityhall/config.lua` 中对应 licenses 的 cost | **P0** |
| B2-3 | 为 qb-cityhall 直接购买路径添加冷却时间（如每 30 天只能免考买一次） | P1 |
