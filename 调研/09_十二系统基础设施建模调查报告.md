### 数据流

```
qb-core PlayerData
  ├── job.name / job.grade        → 职业身份
  ├── gang.name / gang.grade      → 帮派身份
  ├── metadata.licences           → 资质布尔标志 (向后兼容)
  └── metadata.cert_status        → 资质状态 (held/suspended/revoked/unclaimed)
       │
       ▼
custom-career CareerCache[src]
  ├── job_name / job_label / job_grade_name
  ├── org_id / org_label / org_type   ← 自动解析 (job → org)
  ├── gang_name / gang_label / gang_grade_name
  ├── rank_tier (entry/mid/leader/boss)
  ├── department / district / certs
  └── → Player(src).state:set('career_identity', ...)
       │
       ▼
custom-career/client (只读)
  └── LocalPlayer.state.career_identity
```

### 五层校验链

```
Layer 1: Source 权威  → ValidateSource()           — 确保请求来自真实在线玩家
Layer 2: 类型/数值    → sanitizeNumber/String()    — NaN/Infinity/超长字符串拒绝
Layer 3: 权限/职业    → 黑名单 + 白名单 + Job校验   — 职业/帮派变更过滤
Layer 4: 物理距离     → dx*dx+dy*dy+dz*dz ≤ MAX²  — 平方距离(standards §2)
Layer 5: 限流/冷却    → CheckRateLimit + TokenBucket — 防高频刷事件
```

## 🎯 架构总体评价

- Cartel 之外的帮派只有组织骨架无专属玩法（"头重脚轻"）
