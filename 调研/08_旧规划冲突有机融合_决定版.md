### 1.3 架构决策

#### 决策 1.1：供应链物品 ID 必须注册

`custom-cartel/config.lua` 使用了以下物品 ID，必须在 `qb-core/shared/items.lua` 中注册：

| 物品 ID | 角色 | 当前状态 |
|:---|:---|:---:|
| `coca_leaf` | 原料 | ❌ 未注册 |
| `sulfuric_acid` | 原料 | ❌ 未注册 |
| `acetone` | 原料 | ❌ 未注册 |
| `cannabis_bud` | 原料 | ❌ 未注册 |
| `coca_paste` | 中间产物 | ❌ 未注册 |
| `cocaine` | 成品 | ❌ 未注册 |
| `weed_pack` | 成品 | ❌ 未注册 |
| `fertilizer` | 报告声称存在 | ❌ 未注册（且配方中未使用） |
| `markedbills` | 脏钱标记 | ❌ 未注册 |

**行动**: 在 `qb-core/shared/items.lua` 中补全以上物品定义，使供应链在运行时可用。

#### 决策 1.2：配方任务纳入 quest 模板

当前 `custom-cartel/config.lua` 中配方是 cartel 专属的硬编码配置。架构方向：

```
现状:  Config.Cartel.Recipes = { coca_paste, cocaine, weed_pack }   ← cartel 专属
目标:  Config.Quest.Recipes = { ... }                                ← 通用配方系统
       custom-cartel 读取 quest 配方配置
       其他职业（如酿酒师、铁匠、化学家）可复用同一配方引擎
```

配方参数应包括：输入物品、输出物品、加工时长、小游戏类型、失败率、所需资质/等级、加工地点坐标。

**行动**: Phase 2 — 将配方配置从 `custom-cartel/config.lua` 提取到 `custom-quest/config/recipes/` 下，`drug_lab.lua` 改为读取 quest 配方注册表。

#### 决策 1.3：Cartel 成员判定接入 custom-career

当前 `custom-crime/server/crime.lua:402-406` 中 cartel 判定硬编码：

```lua
-- 现状（硬编码）
local gang = Player.PlayerData.gang
isCartel = gang and gang.name == 'cartel'
```

应改为走 `custom-career` 标签比对：

```lua
-- 目标（标签驱动）
isCartel = exports['custom-career']:PlayerMatchesTags(src, { org = 'cartel' })
```

这使任何模块无需知道 "cartel" 这个 gang name，只需知道 org tag。新增帮派组织时零代码改动。

**行动**: Phase 1 — custom-crime v2 重构时统一接入。

#### 决策 1.4：经济出口走 Bus

洗钱的经济入账必须从 `exports['custom-main']:AddScaledMoney` 改为 `Bus.economy.AddScaled`。

**行动**: Phase 1 — 已在 `economy-refactor-memo` 中。

### 2.3 架构决策

#### 决策 2.1：证件定价落地

原始报告 P0 建议 $3,000/$15,000。经讨论，决定采用分层定价：

| 证件 | 当前价格 | 决定价格 | 理由 |
|:---|:---:|:---:|:---|
| driver | $150 | $2,000 | 基础证件，鼓励考试 ($100 报名 + 领证) |
| pilot | $150 | $12,000 | 高价值证件，飞行考试门槛高 |
| heavy | $150 | $5,000 | 重型载具涉及物流运输 |
| boat | $150 | $3,000 | 船舶中等价值 |
| weapon | $150 | $8,000 | 武器证需警方背景审查 |

**行动**: 修改 `custom-certificates/config.lua` 和 `qb-cityhall/config.lua` 两处。

#### 决策 2.2：资质获取纳入公共服务系统

当前资质获取路径分散：
- 驾考 → `custom-quest/config/quests/quest_driver_exam.lua`
- 飞行考 → `custom-quest/config/quests/quest_pilot_exam.lua`
- 市政厅秒买 → `qb-cityhall/server/main.lua`

架构方向：建立 `custom-public-services` 或扩展现有 `custom-quest` 作为统一资质入口：

```
公共服务系统
├── 驾驶学校 (driver/heavy)    → quest_driver_exam.lua + quest_pilot_exam.lua
├── 飞行学校 (pilot)           → 同上
├── 航海学校 (boat)            → 待创建
├── 警察学院 (weapon)          → 待创建 — 需射击考核 + 背景审查
├── 医学院 (medical)           → 待创建 — 需笔试 + 实操
└── 法学院 (lawyer)            → 待创建 — 需笔试
```

每种资质须支持：
- **进入机制**: 报名 → 考核 → 通过 → `custom-certificates:GrantLicense`
- **退出机制**: 吊销 (`RevokeLicense`) / 暂停 (`SuspendLicense`) / 恢复 (`ReinstateLicense`) — 均已实现

**行动**: 加入未来开发备忘录。

#### 决策 2.3：qb-cityhall 冷却时间

市政厅直接买证路径应添加冷却（如每 30 天限购一次），防止玩家反复买证绕过考试。

**行动**: Phase 2 — 在 `qb-cityhall/server/main.lua` 中添加 citizenid-level cooldown。

## 🏛️ 统一架构：组织、职业、资质三元组

三个冲突点的融合方案最终收敛为同一底层架构：

```
                    玩家 (Player)
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    ┌──────────┐   ┌──────────┐   ┌──────────────┐
    │ 组织 (org)│   │ 职业 (job)│   │ 资质 (cert)   │
    │ custom-  │   │ qb-core  │   │ custom-       │
    │ career   │   │ job.name │   │ certificates  │
    └────┬─────┘   └────┬─────┘   └──────┬───────┘
         │              │               │
         └──────────────┼───────────────┘
                        │
                        ▼
         ┌──────────────────────────────┐
         │  PlayerMatchesTags(src, {    │
         │    org  = 'cartel',          │  ← 组织门槛
         │    role = 'drug_dealer',     │  ← 职业门槛
         │    cert = 'weapon',          │  ← 资质门槛
         │    tier = 'mid',             │  ← 阶层门槛
         │  })                          │
         └──────────────┬───────────────┘
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
    ┌──────────┐  ┌──────────┐  ┌──────────┐
    │ 合法玩法  │  │ 犯罪玩法  │  │ 公共服务  │
    │ 职业任务  │  │ 毒品/抢劫 │  │ 驾考/警校 │
    │ quest    │  │ crime v2 │  │ quest    │
    └──────────┘  └──────────┘  └──────────┘
```

**合法玩法与犯罪玩法的统一逻辑**：同一套标签比对引擎（`custom-career:PlayerMatchesTags`）同时服务于合法职业（警察需要 `org='lspd'` + `cert='weapon'`）和犯罪职业（Cartel 需要 `org='cartel'` + `tier='mid'`）。
