## 🔄 2. 数据上下游流转管道规范 (Upstream & Downstream Pipelines)

### 🌊 A. 帮派毒品供应链管道 (The Drug/Cartel Pipeline)

```
【数据上游 (Upstream)】
  1. custom-quest 触发 [种植任务] ➔ 产生化学原料与农产品数据。
  2. 玩家将作物带到卡特尔营地，custom-market (动态交易市场) 写入 [供需数据]，调整收购价格。

【数据中游 (Processing)】
  1. custom-cartel 实验室提供 [加工反应器]。
  2. 校验玩家处于 Madrazo 农场空间坐标围栏内（#(coords - labCoords) < 5.0m）。
  3. 服务端权威判定：扣除原料，进入 30s 反应计时器（不信任客户端时钟）。
  4. 计时结束，向玩家背包写入高纯度毒品物品数据。

【数据下游 (Downstream)】
  1. 玩家使用 `/selldrugs` 指令启动 street cornerselling。
  2. 服务端动态查询 Config.DrugsPrice 作为基础汇率。
  3. 出售完成，调用 EconomyService.AddScaledMoney，收益写入 [dirty_money] (脏钱)。
  4. 脏钱注入 Pawnshop 提款机，按 75% 兑换率转为 [bank] 干净余额，数据进入 DirtyFlush 缓存，60s 后写入 DB。
```

### 🌊 B. DMV 驾考与物理钥匙启动锁管道 (DMV & Vehicle Key Control Pipeline)

```
【数据上游 (Upstream)】
  1. 玩家接取 `driver_license_exam` 任务，生成专用考试车辆（记录 NetID 与临时车牌 Plate）。
  2. custom-quest 发送 [Nonce Token] 给客户端，并在服务端开启速度/路点序列监控。
  3. 客户端按顺序触达 GPS 路点，并在 "STOP" 停止线内上报 Nonce 和静止状态。

【证书状态判定 (State Gating)】
  1. 考试合格，服务端执行 custom-certificates:GrantLicense(source, 'driver')。
  2. 证书数据以 JSON 格式写入玩家 PlayerStateBag: `state.career_identity.certs = ['driver']`。

【数据下游 (Downstream)】
  1. 当平民玩家坐入重卡 (Class 10) 驾驶舱。
  2. 客户端 gameEventTriggered 捕获 `CEventNetworkPlayerEnteredVehicle`。
  3. 客户端读取只读的 `LocalPlayer.state.career_identity`。
  4. 如果 `certs` 中不包含 'heavy'，则触发：
     - 调用 SetVehicleEngineOn(veh, false) 强制熄火。
     - 触发 TaskLeaveVehicle(ped, veh) 强制踢出驾驶舱。
     - 触发安全日志，推送到 Discord 审计。
```

## 🛠️ 3. 面向开发者的落地行动指南 (Actionable Next-Stage Tasks)

为保证项目平稳演进，下一步开发建议优先执行以下 **P0/P1/P2** 级核心重构：

### 🚨 P0 级：生存性与安全硬加固 (立即执行)
1. **任务执照阻断补全**：
   在 [quest_manager.lua](file:///e:/T-City/T-CityLite.base/resources/[custom]/custom-quest/server/quest_manager.lua) 中，补全对 `template.conditions.min_license` 的校验拦截逻辑，禁止无证平民隔空接取重卡/飞行单。
2. **DMV 免考购买价格锚定**：
   重构 [qb-cityhall/server/main.lua](file:///e:/T-City/T-CityLite.base/resources/[qb]/qb-cityhall/server/main.lua)，将免试买证价格设定为考试成本的 30 倍以上（如 $3,000/$15,000），并将直接写入 metadata 的做法替换为标准的 `exports['custom-certificates']:IssueCertificate()` 接口。

### ⚡ P1 级：体验与性能优化 (1 天内)
1. **租车临时钥匙自动分发**：
   在 [quest_logistics_validators.lua](file:///e:/T-City/T-CityLite.base/resources/[custom]/custom-quest/server/quest_logistics_validators.lua) 的租车成功分支中，立即触发 `vehiclekeys:client:SetOwner` 广播，并将临时车牌注册到 `custom-vehicles` 内存中，防止租车锁门后永久卡死任务。
2. **航空物理锁死检测**：
   在 `custom-certificates/client/main.lua` 中部署 1000ms 的慢循环检测，针对平民无证强行开动 ZULU 警用直升机和民航飞机的行为，实施物理断电和强制下车拦截。

### 🎨 P2 级：社会扮演与供应链深化 (2 天内)
1. **市长 KPI 与物流任务挂接**：
   在物流到达交付步骤的 validator 中，触发 `custom-leaders:server:AddCityProgress` 事件，将平民的钢材运量转化为市长的基础设施建设进度，形成“市民劳动 -> 市政工程 -> 官员考评”的社会化闭环。
2. **警用/医用直升机停机坪准入**：
   重构 `qb-policejob` 和 `qb-ambulancejob` 的直升机生成菜单，前置调用飞行执照校验，强制要求紧急救援部门内部分工专职化（必须有专职飞行员）。
