# v0.6b 沙盒社会生态与领袖体系（Sandbox Sociology）

## 版本目标

在犯罪（v0.5）和民间经济（v0.6a）建立后，将服务器推向"玩家主导型严肃角色扮演（Serious RP）"。通过三线领袖体系（市长/警长/黑帮教父）形成自运转的微型社会生态。

**本版本是服务器核心竞争力所在**，也是 Beta 公测的测试重点。

> **Phone-First**：所有领袖终端通过手机 Leader App 访问，无物理终端实体。  
> **前置依赖**：v0.3 career system + v0.4 custom-phone（Job Board / 职业频道）必须完成。

---

## 实施范围

- 三线领袖体系骨架（市长 / 警长 / 黑帮教父）
- 玩家催化剂卡牌系统（3 张合法卡牌）
- 阵营利益互补网络
- 防折磨机制
- 游戏内官方百科（Anti-Meta-Gaming 盲盒设计）
- 领袖 App 动态解锁（通过 v0.4 手机承载）

---

## 架构说明

```
custom-leaders（服务端业务逻辑）
    ↕ 通过 NUI Callback / TriggerClientEvent 通信
custom-phone/ui/src/apps/leader/（前端 UI）
    ├── MayorApp.svelte      ← 市长终端
    ├── SheriffApp.svelte    ← 警长终端
    └── GangBossApp.svelte   ← 教父终端

触发路径：
手机前端 → NUI Callback → custom-phone client → TriggerServerEvent
→ custom-leaders server（业务逻辑）→ 推送到 Job Board / 职业频道 / Discord
```

**`custom-leaders` 无 `ui/` 目录，所有前端由 `custom-phone` 承载。**

## 一、三线领袖体系

### 领袖权限来源

```lua
-- custom-leaders/server/main.lua
-- 所有领袖操作的权限校验
local function CheckLeaderPermission(source, requiredRole)
  local identity = exports['custom-career']:GetPlayerIdentity(source)
  if not identity then return false end
  return identity.rank_tier == 'leader' and identity.primary_role == requiredRole
end
```

```lua
-- server/mayor.lua
-- 国库是独立账户，与玩家个人账户分离
-- 工程奖励从国库扣除（不由市长个人付钱）
-- 催化剂卡牌"加税行政令"会将税收注入国库

local function GetTreasuryBalance()
  local result = MySQL.query.await('SELECT balance FROM server_accounts WHERE account_name = ?', {'city_treasury'})
  return result[1] and result[1].balance or 0
end
```

## 三、阵营利益互补网络

### Beta 最小实现

```
帮派脏钱 → 必须经平民洗白（当铺/洗车店），不可直接存银行
警长发现犯罪 → 职业频道推送警报 → EMS 跟进伤亡 → 医护受保护机制激活
市长工程 → Job Board 派单 → 货车司机运材（城郊往返）→ 财政流通闭环
农民化肥 → 帮派毒品加工（IC 探索） → 帮派收入 → 洗钱 → 平民经济
```

### 阵营间不可分割的依赖关系

| 阵营A | 需要 | 阵营B |
|-------|------|-------|
| 帮派 | 洗白脏钱 | 平民（当铺/洗车店） |
| 帮派 | 毒品原料（化肥） | 农民 |
| 警察 | 线索/维修 | 平民机修师 |
| 市长 | 运输工人 | 货车司机 |
| EMS | 全服保护 | 所有阵营（伤害 EMS 触发全服通缉） |

## 四、防折磨机制

```lua
-- server/main.lua（custom-leaders）

-- 防重复强交互冷却（同一受害人）
local victimCooldowns = {}

RegisterNetEvent('custom-security:strongInteract', function(victimId)
  local src = source
  local key = victimId
  if victimCooldowns[key] and os.time() < victimCooldowns[key] then
    -- 拒绝操作，通知操作者冷却时间
    TriggerClientEvent('QBCore:Notify', src, '该玩家处于保护期', 'error')
    return
  end
  victimCooldowns[key] = os.time() + 3600  -- 60 分钟冷却
end)

-- EMS 保护机制：伤害医护触发全服高悬赏
RegisterNetEvent('custom-security:attackedEMS', function(victimId)
  -- 全服广播悬赏通缉
  -- 推送 Discord #combat-log
  TriggerClientEvent('QBCore:Notify', -1,
    '⚠️ 有人袭击医护人员！高额悬赏已发布！', 'error')
end)
```

## 五、游戏内百科（custom-wiki）

### Anti-Meta-Gaming 内容边界（严格执行）

✅ **允许记载**：
- 合法职业介绍、工资范围、上班方式
- 合法催化剂卡牌效果和获取条件（3 张合法卡牌）
- 领袖终端操作指南（如何查看市长工程任务）
- 医疗/急救流程、如何联系 EMS
- Serious RP 扮演道德规范
- 新手入门指南（如何赚第一桶金）
- 合法经济职业介绍

❌ **绝对禁止记载**：
- 任何犯罪触发方式、位置、条件
- 洗钱流程、黑市位置、地下汇率
- 毒品加工配方或原料（化肥的非法用途）
- 暗线卡牌的存在（任何提示都不行）
- 如何加入帮派的具体方式（必须 IC 探索）
