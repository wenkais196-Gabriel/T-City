# v0.6a 民间经济职业生态（Civilian Economy）

## 版本目标

建立服务器经济循环的**物质基础**。民间经济职业生产的原材料同时流入：
- ✅ **合法链路**：市长城市工程（建材/运输）、餐厅/市场（食物）
- ✅ **非法链路**：毒品生产（化肥）、武器制造（矿石）
- ✅ **服务链路**：机修师服务所有阵营的车辆

> **并行说明**：本版本与 v0.5（犯罪）和 v0.6b（社会生态）并行开发。民间经济是 v0.6b 市长工程的物质依赖，需在市长终端联调之前完成。

---

## 地图全开发目标

```
矿工（郊区工业区）→ 货车司机（城郊往返）→ 城区建筑工地 → 市长政绩+
渔民（港口/近海）→ 城区餐厅/市场 → 平民消费 → 经济流通
农民（郊区农场）→ 化肥（城郊结合部黑市）→ 毒品加工 → 帮派收入
机修师 ← 维修费 ← 警察/帮派/平民（所有车辆用户）
```

货运路线强制包含**城区↔郊区往返**，确保郊区地图有玩家活动，打破"只玩市中心"的惰性。

## 自研资源：custom-mining（矿工）

### 设计目标
- 采矿点分布在郊区/工业区，强制玩家离开市中心
- 简单采集小游戏（复用 `progressbar`）
- 矿石产出接入两条链路：市长工程建材 / 黑市武器原料

### 资源结构

```
resources/[custom]/custom-mining/
├── fxmanifest.lua
├── config.lua          # 采矿点坐标、产出物品、采集时间、挖矿工具
└── server/
    ├── main.lua        # 采集事件处理、背包物品给予
    └── client.lua      # 采矿点 Blip、交互点、progressbar 小游戏
```

### 采矿点配置（郊区分布）

```lua
-- config.lua
Config.MineLocations = {
  {
    label   = "砂石采石场",
    coords  = vector3(-595.9, 3492.7, 30.0),   -- 郊区砂石场
    zone    = "industrial",
    outputs = { { item = "iron_ore", min = 2, max = 5 } }
  },
  {
    label   = "山区矿井",
    coords  = vector3(2961.9, 2784.3, 41.0),   -- 东部山区
    zone    = "rural",
    outputs = { { item = "iron_ore", min = 3, max = 6 }, { item = "stone", min = 1, max = 3 } }
  },
}

Config.MiningTime = 8000       -- 采集动画时长（ms）
Config.RequiredTool = "pickaxe" -- 需要背包内有矿镐
```

### 物品接入

```lua
-- 矿石输出物品（需在 qb-core/shared/items.lua 注册）
["iron_ore"]   = { name = "iron_ore",  label = "铁矿石",  weight = 500, ... }
["stone"]      = { name = "stone",     label = "建筑石料", weight = 1000, ... }
["raw_copper"] = { name = "raw_copper",label = "粗铜矿",  weight = 500, ... }
```

接入 `custom-career` 标签（`civilian·miner`）：
```lua
-- 采集成功后记录职业贡献（供 KPI 统计）
exports['custom-career']:RecordJobAction(src, 'mine', quantity)
```

## 自研资源：custom-trucking（货车司机）

### 设计目标
- 货运任务通过**手机 Job Board** 接单（不需要 NPC）
- 市长发布城市工程后，任务自动推送到 Job Board
- 路线强制包含城郊往返（从郊区仓库运到城区工地）

### 资源结构

```
resources/[custom]/custom-trucking/
├── fxmanifest.lua
├── config.lua          # 仓库/工地坐标、货物类型、奖励配置
└── server/
    ├── main.lua        # 任务发布到 Job Board、完成验证、结算
    └── client.lua      # GPS 路点管理、到达点打卡逻辑
```

### 任务流程（纯手机驱动）

```
市长手机市长终端 → 发布「道路修缮」工程
          ↓
server/main.lua 写入 phone_jobboard 表（target_tags: {role:"civilian", ...}）
          ↓
TriggerClientEvent('phone:jobboard:newJob', -1, jobData)
          ↓
符合标签的货车司机手机 Job Board 弹出任务通知
          ↓
司机点击接单 → 货物种类 + 取货坐标（郊区仓库）+ 送达坐标（城区工地）
          ↓
GPS 路点：郊区仓库 → 城区工地
          ↓
取货（载货量检查）→ 驾车前往 → 送达打卡
          ↓
server 验证完成 → AddScaledMoney 结算
          ↓
市长 KPI 积分 + 1；Discord #leader-log 记录
```

### 货运路线配置

```lua
-- config.lua
Config.Routes = {
  {
    name    = "砂石运输",
    pickup  = { coords = vector3(-595.9, 3492.7, 30.0), label = "郊区砂石场" },
    dropoff = { coords = vector3(-280.0, -960.0, 30.0), label = "城区建筑工地" },
    cargo   = "stone",           -- 需要背包内有 stone
    quantity = 5,                -- 需要 5 个
    reward  = 800,
  },
  {
    name    = "铁矿运输",
    pickup  = { coords = vector3(2961.9, 2784.3, 41.0), label = "东部矿井" },
    dropoff = { coords = vector3(449.0, -1003.0, 25.0), label = "港口卸货点" },
    cargo   = "iron_ore",
    quantity = 4,
    reward  = 1200,
  },
}
```

## 数据库

```sql
-- 货运任务记录（供 custom-trucking 使用）
CREATE TABLE trucking_jobs (
  id           INT AUTO_INCREMENT PRIMARY KEY,
  jobboard_id  INT,                     -- 关联 phone_jobboard.id
  route_name   VARCHAR(100),
  taken_by     VARCHAR(50),
  status       VARCHAR(20) DEFAULT 'in_progress',
  started_at   DATETIME DEFAULT NOW(),
  completed_at DATETIME
);

-- 矿工采集记录（供 KPI 统计和经济日志）
CREATE TABLE mining_logs (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  citizenid   VARCHAR(50),
  location    VARCHAR(100),
  item        VARCHAR(50),
  quantity    INT,
  timestamp   DATETIME DEFAULT NOW()
);
```

## 供应链联调测试

联调顺序（必须在以下资源全部可用后进行）：
