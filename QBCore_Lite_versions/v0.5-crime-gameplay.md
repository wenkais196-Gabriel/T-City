# v0.5 犯罪玩法

## 版本目标

在基础 RP 和经济安全边界（v0.3）稳定后，逐步加入犯罪玩法，形成可控的风险、收益和执法对抗闭环。

本版本强调分阶段启用，不一次性打开所有犯罪资源，并确保所有犯罪奖励接入 v0.3 的统一经济出口。

> **供应链联动**：v0.6 民间经济（农民化肥）是本版本毒品链路的原料来源，两版本需要配合联调。

---

## 实施范围

- 加入低风险犯罪玩法（便利店抢劫）
- 加入中风险犯罪玩法（毒品）
- 所有犯罪奖励接入 `custom-economy` 统一出口
- 服务端安全校验（在线警察数量 / 距离 / 冷却时间）
- 记录所有高价值犯罪事件日志

## 毒品供应链联动（接 v0.6 民间经济）

毒品原料链路（需要 v0.6-civilian-economy 完成后联调）：

```
农民（郊区农场）→ 化肥（背包物品）
                      ↓
               帮派成员收购化肥（城郊结合部交易点）
                      ↓
               毒品加工（qb-drugs 加工配方，消耗化肥）
                      ↓
               毒品出售（街头/固定出售点）
                      ↓
               帮派收入（经 AddScaledMoney 出口结算）
                      ↓
               脏钱需要洗白（当铺/洗车店）
```

> **重要**：化肥作为毒品原料，玩家需要 IC 探索才能发现链路，不在官方 Wiki 中记载。

## 服务端校验重点

所有犯罪事件必须经过以下服务端校验，不允许客户端直接决定结果：

| 校验项 | 说明 |
|--------|------|
| 在线警察数量 | `qb-storerobbery`：至少 2 名在岗警察；`qb-drugs` 加工：1 名；出售：0 名 |
| 玩家距离 | 服务端验证玩家与触发点的实际距离 |
| 所需物品 | 服务端验证背包内物品（不信任客户端）|
| 冷却时间 | 同地点抢劫：30 分钟；毒品出售：15 分钟 |
| 奖励上限 | 单次最高奖励上限写入 `economy.cfg` Convar |
| 重复触发 | 同玩家短时间内多次触发同一事件 Rate Limit |

### 接入 custom-economy 示例

```lua
-- ❌ 禁止：直接调用 QBCore Money API
QBCore.Functions.AddMoney(src, 'cash', reward)

-- ✅ 正确：通过统一出口
exports['custom-economy']:AddScaledMoney(src, reward, 'store_robbery')
```

## 犯罪与执法互动

```
犯罪触发 → 警报推送到警察职业频道（手机）→ 警察响应
                ↓                                    ↓
         犯罪日志写入 #economy-log           警长可在手机看到警报位置
                ↓
         犯罪收益流向洗钱链路（v0.6）
```

### 在线警察数量联动

```lua
-- 服务端：检查当前在岗警察数量
function GetOnDutyPoliceCount()
  local count = 0
  for _, playerId in ipairs(QBCore.Functions.GetPlayers()) do
    local Player = QBCore.Functions.GetPlayer(playerId)
    if Player.PlayerData.job.name == 'police' and Player.PlayerData.job.onduty then
      count = count + 1
    end
  end
  return count
end
```

## 已知风险点

- 犯罪资源通常事件多、奖励高，是外挂重点攻击面，必须确保 v0.3 安全边界已生效
- 毒品原料链路（农民化肥）在 v0.6-civilian-economy 完成前暂时跳过，先用替代原料测试
- 一次性开放过多犯罪玩法会破坏经济平衡；Beta 阶段严格只开放两类犯罪
