# v0.7b 智能车载中控屏与诊断系统 (Sleek Glassmorphic Dashboard NUI)

## 版本目标

在 `v0.7a` 重构完基础钥匙逻辑与物流任务模板后，开发并启用全新的**“智能车载中控屏 (Unified Vehicle Dashboard)” NUI 面板**，彻底解决车辆多按键绑定的交互冲突，为载具玩家、特殊职业（警方、航空、航海）提供更具沉浸感的控制体验。

---

## 实施范围

- **中控屏 NUI 系统 (Svelte / Vite Standalone UI)**：
  - 采用毛玻璃美学设计（Glassmorphism），背景带动态霓虹氛围灯效。
  - 支持快捷键一键唤醒（默认在车内时按下 **I** 键或通过 Radial Menu 唤醒）。
  - 根据车型自适应色系：货卡/卡车为工业橙，警车/救护车为警用蓝，飞机/直升机为航空绿，高档跑车为极光紫。
- **四大仪表与诊断标签页 (Tabs)**：
  - **📊 诊断仪表**：实时获取并同步电压、机油寿命、发动机受损度、车身受损度、冷却水温（动态模拟）。
  - **🛠️ 系统控制**：开关引擎、中控锁控制、车窗物理升降、打开货舱门/后机底舱。
  - **📦 货运任务**：接取物流运单后启用，车内快捷装卸、电子戳确认、物理拖车平挂一键气放脱开。
  - **🚨 职业控制台**：
    - *警察 (police)*：测速雷达（前/后）、Megaphone 喊话喇叭（联动 `pma-voice` 物理音量放大）、警笛控制器（Yelp/Wail/Priority）、通缉犯数据库查阅。
    - *飞机 (aviation)*：雷达高度表、气温气压偏航指示、应答机代号（Transponder）调节。
    - *船只 (marine)*：锚点锁定（防洋流漂移）、声呐鱼群深度检测。

## 车载中控仪“四原则”设计细节

### 1. 安全性 (Security) — 严堵刷钥匙与远程注入漏洞
* **主驾驶身份校验**：中控屏所有传回服务端的控制指令（如引擎起停、车锁、物理脱钩），服务端首先通过 `GetVehiclePedIsIn(ped, false)` 获取实体，并校验 `GetPedInVehicleSeat(veh, -1) == ped`（必须在驾驶席），否则直接拒绝。
* **物理距离校验**：对于锁车/解锁等可能隔空操作的功能，服务端强制对玩家和载具进行 `#(GetEntityCoords(ped) - GetEntityCoords(veh)) < 5.0` 距离校验，严防外挂跨地图刷锁。
* **职业鉴权与服务端二检**：针对“警车测速”、“PA扩音喊话”等高权限应用，服务端会在玩家点击屏幕的瞬间实时校验其 `job` 属性，防范普通市民利用漏洞发送警用指令。
* **操作 Rate Limit**：为防止玩家快速疯狂点击“中控锁”或“引擎开关”产生高频网络包阻塞，引入 1000ms 的操作冷却墙。

### 2. 高性能 (Performance) — 零Tick挂起与定时数据推流
* **事件激活**：中控仪 NUI 仅在玩家在车内按下 **I** 键并开启 UI 时才激活；UI 关闭时，中控仪客户端线程完全处于挂起（Sleep）状态。
* **低频定时器推流**：对于燃油、电池电压、机油寿命等**非突变数据**，采用低频定时器推送（如每 500ms 至 1000ms 刷新一次），前端使用 CSS Transition 实现指针平滑滑动，消除 0ms 每一帧的渲染消耗。
* **轻量前端资源**：Svelte 编译产物极小（< 50KB），首屏加载快，启用 GPU 硬件加速，零渲染死锁风险。

### 3. 模块化 (Modularity) — 前后端应用插件化
* **应用插件化**：中控屏的四个 Tab 页面（`Diagnostics`、`LogisticsApp`、`PolicePatrol`、`AviationNav`）在前端 UI 和 Lua 后端中全部为独立子模块。
* **依赖解耦**：载具基础控制独立于物流系统，物流系统只在中控仪的 `Logistics Tab` 提供接口，两者的逻辑代码完全隔离，互不干涉。

### 4. 可拓展性 (Extensibility) — 开放式插件注册接口
* **外部 App 动态插入**：设计了中控仪**外部 App 注册 API**，允许其他资源在初始化时动态向车载面板插入自定义 App，无需修改车载控制仪核心或重新打包前端。
* **接口设计**：
  ```lua
  -- 外部第三方资源直接调用此 API 注册新 App 页面
  exports['custom-vehicles']:RegisterDashboardApp({
      id = 'taxi_meter',
      label = '出租车计价器',
      icon = 'fa-taxi',
      job = 'taxi', -- 仅出租车司机可见
      nui_event = 'taxi:client:showMeter'
  })
  ```

## 核心设计细化

### 1. 中控仪操作与印章交单 (In-Cab Delivery Dashboard)

为了极大地打磨“欧卡级”交单的流畅度，物流交货不再使用繁琐的下车 E 键，而是坐在车内通过车载控制屏进行“三合一印章”戳印交货：

- **验证原理**：
  - 玩家到达交付点，中控屏“货运任务”激活，显示当前电子戳信息。
  - 点击“电子印章交货”后，系统在服务端同时验证：
    - `玩家ID`（CitizenID） == 接单人；
    - `车辆ID`（NetID & Plate） == 绑定货运卡车；
    - `货物挂载实体`（Cargo Prop 或平底拖车）正常附着未遗失。
  - 验证秒级通过，后台直接结算，省去了繁琐的上下车。

---

### 2. 特殊职业扮演支持 (Job Megaphone & Radar)

#### A. 警车测速与喊话系统 (Megaphone)
- **扩音喊话 (PA System)**：警车中控仪集成了车外扩音放大按钮。激活时，玩家对麦克风说话，声音会在车顶警笛扬声器输出，传播距离物理拉长至 50-70 米，并附带扩音器混响和电音啸叫滤镜，扮演感极强。
- **警笛分级控制**：解决 GTA 原版只能开/关警笛的单调设置，中控屏允许单独选择声效（Wail 巡航哨、Yelp 追捕哨、Priority 抢道哨、警灯无声闪烁模式）。
- **车载测速雷达**：开启后，自动捕获车前 30 米扇形区域内车辆的速度、车型和牌照，超速自动警报抓拍，抓拍数据自动存入警车电脑，便于开具罚单。

#### B. 船只防漂移锚定系统 (Boat Anchor)
- 在水面上开船时，GTA 原版的船只在引擎熄灭后依然会因为洋流水流不停向下游漂移，非常不方便。
- 船只中控仪增加了“抛锚 (Drop Anchor)”功能：点击后，服务端强制将船只的 Physics 速度重置为 0，并固定其坐标，直到起锚。
