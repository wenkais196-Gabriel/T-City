# v0.4 自研手机系统（custom-phone）

## 版本目标

自研一套性能优先、Phone-First 架构的手机系统，替代现有 `qb-phone`。

核心设计目标：
- **高频低占用**：消息推送不轮询，手机关闭时 CPU 占用归零
- **模块化 App**：每个功能是独立 Svelte 组件，便于后期新增 App
- **领袖权限动态解锁**：`rank_tier = leader` 时手机自动注册专属终端 App
- **统一交互入口**：所有游戏系统（任务/领袖终端/经济）通过手机完成，无需物理 NPC 或终端

> **并行说明**：本版本从第 2 周与 v0.3 并行开发，不需要等 v0.3 完全验收。数据库表在 v0.3 第 3 周统一建完。

---

## 技术栈

| 层 | 技术 | 原因 |
|----|------|------|
| 前端框架 | **Svelte + Vite** | 编译时消除运行时框架开销，打包体积最小 |
| 类型约束 | TypeScript | 减少 Lua↔NUI 消息协议的运行时错误 |
| 状态管理 | Svelte Stores | 零依赖，轻量响应式 |
| 打包目标 | < 250KB gzipped | 保证玩家加载速度 |
| Lua 端 | FiveM 原生 | 无额外依赖 |

## Phone-First 架构原则

```
手机 = 所有游戏系统的主要交互界面
NPC  = 仅用于商店等必须线下存在的场景
物理终端 = 完全不使用（领袖终端集成在手机内）
```

**所有通过手机完成的操作**：
- 银行存取款和转账
- 职业申请/上下班
- 市长城市工程发布与领取（Job Board）
- 警长巡逻调度和 GPS 下发（警长终端 App）
- 帮派指标发布（教父终端 App）
- 工资/任务结算通知
- 玩家间通讯（短信/职业频道）

## 数据库表

```sql
-- 消息表
CREATE TABLE phone_messages (
  id              INT AUTO_INCREMENT PRIMARY KEY,
  sender_number   VARCHAR(10) NOT NULL,
  receiver_number VARCHAR(10) NOT NULL,
  message         TEXT NOT NULL,
  timestamp       DATETIME DEFAULT NOW(),
  is_read         BOOLEAN DEFAULT FALSE,
  INDEX idx_receiver (receiver_number),
  INDEX idx_sender   (sender_number)
);

-- 联系人表
CREATE TABLE phone_contacts (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  citizenid   VARCHAR(50) NOT NULL,
  name        VARCHAR(100) NOT NULL,
  number      VARCHAR(10) NOT NULL,
  UNIQUE KEY  uq_contact (citizenid, number)
);

-- CityFeed 帖子
CREATE TABLE phone_cityfeed (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  citizenid   VARCHAR(50) NOT NULL,
  content     TEXT NOT NULL,
  likes       INT DEFAULT 0,
  timestamp   DATETIME DEFAULT NOW(),
  INDEX idx_time (timestamp)
);

-- Job Board 任务表（与 leader_kpi_tasks 联动）
CREATE TABLE phone_jobboard (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  task_id       INT,                    -- 关联 leader_kpi_tasks.id
  title         VARCHAR(100),
  description   TEXT,
  target_tags   JSON,                   -- 可接单的职业标签过滤器
  reward        INT DEFAULT 0,
  status        VARCHAR(20) DEFAULT 'open',   -- open/taken/completed
  taken_by      VARCHAR(50),
  posted_at     DATETIME DEFAULT NOW(),
  deadline      DATETIME,
  INDEX idx_status (status)
);
```

## Lua ↔ NUI 消息协议规范

### 统一消息格式

```lua
-- Lua → NUI（服务端/客户端 → 手机前端）
SendNUIMessage({
  action = "phone:openApp",    -- 动作标识（命名空间:动词）
  app    = "messages",         -- 目标 App（可选）
  data   = { ... }             -- 数据载荷
})

-- NUI → Lua（手机前端 → 客户端 Lua）
RegisterNUICallback("phone:sendMessage", function(data, cb)
  -- data: { to = "1234567890", message = "你好" }
  TriggerServerEvent('phone:server:sendMessage', data.to, data.message)
  cb({ success = true })
end)
```

### 关键 Action 枚举

| Action | 方向 | 说明 |
|--------|------|------|
| `phone:open` | Lua→NUI | 打开手机 |
| `phone:close` | Lua→NUI | 关闭手机 |
| `phone:newMessage` | Lua→NUI | 推送新消息（服务端触发） |
| `phone:newNotification` | Lua→NUI | 推送系统通知 |
| `phone:jobboard:newJob` | Lua→NUI | 新任务推送到 Job Board |
| `phone:faction:receive` | Lua→NUI | 职业频道新消息 |
| `phone:registerLeaderApp` | Lua→NUI | 动态注册领袖 App 图标 |
| `phone:removeLeaderApp` | Lua→NUI | 撤职后移除领袖 App 图标 |

## 性能规范

```lua
-- ❌ 禁止：手机关闭时依然存在的定时器
-- ✅ 正确：手机关闭时清理所有定时器
local phoneThread = nil

RegisterNUICallback('phone:open', function(_, cb)
  phoneThread = CreateThread(function()
    while IsPhoneOpen() do
      -- 手机内的循环逻辑
      Wait(1000)
    end
  end)
  cb({})
end)

RegisterNUICallback('phone:close', function(_, cb)
  -- 手机关闭时无需手动清理，循环会自动退出
  cb({})
end)
```

强制规则：
- 消息推送使用服务端 `TriggerClientEvent`，**禁止客户端轮询**
- 通知更新频率上限：每秒最多 1 次 `SendNUIMessage`
- 手机关闭后所有 NUI 定时器必须停止
- 打包产物目标：**< 250KB gzipped**
- 联系人/消息列表超过 50 条启用虚拟滚动

## 职业频道服务端路由

```lua
-- server/faction.lua

-- 向特定标签的所有在线玩家广播频道消息
function BroadcastToFaction(role, tier, message)
  for _, playerId in ipairs(QBCore.Functions.GetPlayers()) do
    local identity = exports['custom-career']:GetPlayerIdentity(playerId)
    if identity and identity.primary_role == role then
      if tier == nil or identity.rank_tier == tier then
        TriggerClientEvent('phone:faction:receive', playerId, {
          role    = role,
          tier    = tier,
          content = message,
          time    = os.time()
        })
      end
    end
  end
end

-- 示例：警长向所有警察发巡逻令

-- 示例：教父向帮派基层发指标
-- BroadcastToFaction("gang", "entry", { type="quota", name="收银机指标", deadline=7200 })
```

## 领袖 App 动态解锁

```lua
-- client/main.lua

-- 玩家登录/职业变更时动态注册领袖 App
AddEventHandler('QBCore:Client:OnPlayerLoaded', function()
  local identity = exports['custom-career']:GetLocalIdentity()
  if identity and identity.rank_tier == 'leader' then
    SendNUIMessage({
      action = 'phone:registerLeaderApp',
      role   = identity.primary_role   -- 'mayor' / 'police' / 'gang'
    })
  end
end)

-- 收到 custom-admin demote 事件时移除领袖 App
RegisterNetEvent('custom-career:client:tierChanged', function(newTier)
  if newTier ~= 'leader' then
    SendNUIMessage({ action = 'phone:removeLeaderApp' })
  end
end)
```

## Job Board 完整流程

```
市长手机 → 市长终端 App → 发布城市工程任务
         ↓
server/jobboard.lua 写入 phone_jobboard 表
         ↓
TriggerClientEvent('phone:jobboard:newJob', -1, jobData)  ← 广播全服
         ↓
符合标签的玩家手机 Job Board 收到新任务通知
         ↓
玩家点击接单 → server 校验标签 + 更新状态为 'taken'
         ↓
GPS 路点推送到玩家地图
         ↓
玩家到达目标点打卡
         ↓
server 验证完成 → 调用 custom-economy:AddScaledMoney 结算
         ↓
玩家手机通知中心推送：「任务完成！获得 $XXX」
市长 KPI 积分 +1
```
