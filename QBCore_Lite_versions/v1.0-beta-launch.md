# v1.0 Open Beta 上线验收与发布清单

## 版本目标

完成所有 v0.x 版本的系统联调，通过内测验收，发布开放公测（Open Beta）。

开放公测的定位：
- **收集真实玩家数据**，调整经济平衡、任务奖励、犯罪风险
- **测试三线领袖生态**，观察市长/警长/教父对玩家行为的影响
- **建立玩家社群**，为后续转白名单私服做准备

## 内测联调测试用例

### 经济安全测试
- [ ] 客户端事件注入：直接触发 AddMoney，确认被服务端拦截

- [ ] 手机开关循环 100 次，无 CPU 累积泄漏
- [ ] 100 条消息推送压测，延迟 < 200ms
- [ ] 手机关闭后所有 NUI 定时器停止，msec/tick 归零

- [ ] 市长手机发布道路修缮 → Job Board 推送 → 货车司机接单 → GPS 引导 → 完成打卡 → 结算 → 通知（全程无 NPC 介入）

- [ ] 教父终端下达收银机指标 → 帮派频道通知 → 成员完成 → 集体结算

### 三线并行压测
- [ ] 同时运行：市长工程 + 警长巡逻 + 帮派指标（确认职业频道消息不互相干扰）

### 供应链端到端测试
- [ ] 矿工采矿 → 货车司机运至工地 → 市长政绩增加 → 催化剂卡牌掉落

```cfg

set onesync on              # ✅ 已配置（v0.1 阶段）
set sv_maxClients 32        # Beta 阶段限制人数（防止初期 bug 被大量触发）
```

## Beta 公测收集指标

### 经济健康指标
- 全服平均日收入（按职业分类）
- 经济通胀趋势（物价/工资比值）
- 催化剂卡牌使用频率和倍率峰值

### 领袖生态指标
- 三个领袖岗位各自带动的活跃下层玩家数
- 市长工程平均完成率（发布→接单→完成比例）
- 警长巡逻平均参与人数
- 帮派指标平均完成率

### 玩法健康指标
- 犯罪/执法互动频率（警匪对抗是否健康）
- 触发防折磨冷却的次数（是否有玩家恶意刷取）
- Combat Logging 警告次数

### 技术健康指标
- 手机系统客户端性能（msec/tick 平均值）
- 服务器平均 ms/frame
- 数据库查询平均延迟
- 错误日志每日数量
