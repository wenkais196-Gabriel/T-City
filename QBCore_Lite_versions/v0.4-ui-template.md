# v0.4 复杂 UI 样板

## 版本目标

选择一个复杂 UI 作为 TypeScript + Svelte + Vite 样板，为后续手机、HUD、银行、MDT 等 NUI 改造建立标准。

推荐先选 HUD 或银行，避免一开始重做手机、背包这类大系统。

## 实施范围

- 确定首个 NUI 样板资源
- 建立 TypeScript 类型约束
- 建立 Vite 打包流程
- 规范 Lua 与 NUI 的消息协议
- 控制图片、动画和打包体积
- 建立 UI 关闭后的清理逻辑

## 候选 UI

```text
HUD
银行
警用 MDT
手机
背包
```

推荐优先级：

```text
HUD 或银行 > MDT > 手机 > 背包
```

## NUI 性能规则

- 避免大量高清图片。
- 避免每帧 `SendNUIMessage`。
- 关闭 UI 后停止定时器。
- 列表使用分页或虚拟滚动。
- 只在状态变化时更新 UI。
- 打包产物尽量小。

## 交互分层

适合轻量菜单：

```text
任务点
小地图图标
NPC 交互
商店菜单
职业选择
车库列表
```

适合 NUI：

```text
手机
背包
HUD
银行
警用 MDT
角色创建
管理后台
小游戏
```

## 验收标准

- 样板 UI 能正常打开、关闭和刷新数据。
- Lua 与前端消息协议有文档。
- UI 关闭后无持续无用定时器。
- 打包产物路径被资源正确加载。
- v0.1 到 v0.3 的核心流程不被破坏。

## 风险点

- NUI 资源体积可能拖慢玩家加载。
- 频繁消息更新会造成客户端卡顿。
- UI 改造容易扩大范围，需要严格限制本版本只做一个样板。
