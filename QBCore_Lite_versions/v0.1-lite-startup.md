# v0.1 精简启动

## 版本目标

建立 Lite base 的最小可运行启动链，替换 `ensure [qb]` 的粗粒度加载方式。

保留登录、出生、背包、HUD、语音和自定义主资源，为后续模块化迭代打基础。

## 实施范围

- 复制新 base：`D:\txData\T-CityLite.base`
- 保留原始目录：`D:\txData\QBCore_CDB34E.base`
- 重写新 base 的 `server.cfg`
- 建立 `configs\modules` 模块配置目录
- 只启动核心资源和玩家进入流程必需资源
- 记录启动缺失依赖和报错


## 验收标准

- 服务器能从新 base 启动。
- 玩家能创建或选择角色。
- 玩家能正常出生。
- 背包、HUD、天气同步、语音能基本工作。
- 控制台缺失依赖被记录到后续任务中。
- `server.cfg` 中不再使用 `ensure [qb]`。

## 风险点

- 某些资源可能隐式依赖未启动的 qb 资源。
- `qb-apartments`、`qb-spawn`、`qb-multicharacter` 之间启动顺序需要实测。
- 背包、HUD 可能依赖配置项或 shared items/jobs。
- 旧资源中可能存在自动触发的客户端事件报错。
