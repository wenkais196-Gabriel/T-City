# T-City 职业、资质与组织任务重构讨论蓝图 (v1.0)

## 🛡️ 讨论时的四大核心设计准则回顾

为了确保最终输出的手册能够完美用于指导 Wiki 编写与未来的功能开发，每一个具体的职业任务设计在讨论时都必须回答以下四个问题：
1. **模块化如何保障？** （该任务使用了哪些原子节点？它如何解耦，不产生多余的代码堆积？）
2. **高性能如何实现？** （在本地交互和轮询上，如何应用 Zero-Tick 事件触发逻辑？）
3. **安全与防刷机制？** （服务端如何建立绝对权威的防外挂校验链？是否使用了时间戳、物理距离或状态核对？）
4. **扮演沉浸感（Identity Utility）与组织分成？** （这个职业的任务细节是什么？它如何为其他职业（如技工、运输）提供经济流转？收益如何在个人与部门金库中分配？）
