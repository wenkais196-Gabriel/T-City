# 设计文档：商店抢劫重构 — "罪与罚" 沉浸式玩法

## 1. 现状分析

### 当前问题
| 维度 | 现状 | 问题 |
|------|------|------|
| 玩法逻辑 | 撬锁小游戏 → 25秒站立等待 → 自动收钱 | 25秒干站毫无逻辑，"抢收银机"变成"等收钱" |
| 代入感 | NPC恐惧逃跑 + 进度条 | 缺少叙事、环境音效、店主互动、紧张感设计 |
| 教育意义 | 无 | 纯收益循环，抢劫被简化为"工具→收益"，间接美化犯罪 |
| 奖励链 | 直接得 markedbills，可立即通过当铺洗钱 | 缺少"赃物处理的道德困境"环节 |
| 失败惩罚 | 撬锁断工具 | 被抓没有长期后果，加速冷却即可重来 |
| 警察响应 | 自动报警 + blip | 警察没有"赶到现场"的实际压力机制 |

### 核心痛点
- **25秒站桩**：最糟糕的设计——玩家无事可做，反而鼓励挂机
- **零叙事**：玩家只是在执行一个"操作→收益"的机械动作
- **无道德维度**：犯罪没有任何心理负担或社会后果的设计

## 2. 设计目标

### 核心体验目标
1. **每个步骤有逻辑动机**：为什么撬锁→为什么翻收银机→为什么逃跑，每一步都有合理的行为逻辑
2. **沉浸式细节**：通过动画、音效、环境叙事、NPC反馈构建紧张感
3. **"罪与罚"教育内核**：犯罪玩法最终引导玩家反思——不是不能做，但要面对后果

### 教育意义目标
- **犯罪有代价**：不仅仅是"被抓了进监狱"，而是设计心理/社会/经济多维度的负面反馈
- **引人向善**：通过叙事和NPC互动，让玩家在角色扮演中自然感受到"犯罪不是好选择"
- **退出机制**：给玩家"放弃犯罪"的体面出口，不是"要么成功要么被抓"的两极

## 3. 玩法流程设计（重构后全链路）

### Phase 1: 侦查（新增）
```
玩家靠近商店 → 出现侦查提示 → 按ALT环视店内
  → 成功: 获得"商店情报"(店内布局、店员人数、摄像头位置)
  → 信息不足: 强行进入触发"可疑人员"警报（增加后续风险）
```
- **教育点**：犯罪需要计划——冲动犯罪更容易被抓

### Phase 2: 撬锁（改造现有）
```
锁撬工具开门 → 3阶段迷你游戏:
  1. 探针找锁芯 (鼠标微调) 
  2. 弹子定位 (WASD力度控制)
  3. 旋转开锁 (时机把握)
  失败: 工具损坏概率保留
  成功: 门解锁(不是直接收钱!)
```
- **教育点**：用"探→定→转"三阶段模拟真实撬锁的复杂性和难度

### Phase 3: 翻找收银机（全新设计）
```
门开后 → 手动翻找动画
  → 按进度条阶段收钱 (10秒主动操作，不是25秒站桩)
  → 每2秒触发一个"环境威胁检查":
    - 有警察靠近? → 进度加快但有掉落风险
    - 店主NPC醒来/尖叫? → 必须决定: 继续抢 or 逃跑
  → 可选: 拿走多少？
    - 全拿(最大收益+最久时间+最高被抓风险)
    - 拿一半(中等收益+中等风险)
    - 只拿零钱(低收益+快速脱身)
```
- **教育点**：贪心 vs 安全的博弈——犯罪中的"度"的思考

### Phase 4: 逃跑/善后（全新设计）
```
拿到钱后 → 进入"逃跑阶段"
  → 选择逃跑路线:
    A. 正门冲刺(快速但容易被警察看到)
    B. 后巷逃跑(安全但慢)
    C. 混入人群(需换装道具/步行)
  → 成功逃脱后:
    - 赃物标记为"热赃物"(hot goods) 状态
    - 30分钟内被警察搜身会被查到
    - 需要到"安全点"处理赃物(自己家/车库)
```
- **教育点**：犯罪不是"拿到钱就结束了"——赃物处理才是真正的挑战

### Phase 5: 处理赃物（全新—道德选择题）
```
热赃物状态 → 需要选择处理方式:
  A. 存入当铺 → 快速拿钱但大额贬值(50%) + 警方记录关联
  B. 找黑市买家 → 中额贬值(25%) + 可能被黑吃黑
  C. 藏匿等冷 → 原价值但48小时不能花 + 偶尔"良心不安"系统消息
  D. 🆕 送回商店 → 匿名归还，获得"良心点数"buff(+10%经验获取24h)
    (教育核心: 给玩家一个"做好事"的出口)
```
- **教育点**：**选项D**是关键设计——犯罪后有一个"回头"的机会

## 4. 沉浸式细节设计

### 环境叙事
| 时刻 | 细节 |
|------|------|
| 进入商店 | 背景轻音乐 → 你靠近收银机时音乐产生不和谐音 |
| 撬锁时 | 远处警笛声随机触发(真假难辨，营造紧张感) |
| 翻找时 | 收银机抽屉内部特写UI + 硬币掉落音效 |
| 逃跑时 | 心跳音效 + 屏幕边缘泛红 + 呼吸急促音频 |
| 成功逃脱 | 深呼气音效 + 环境音恢复平静 |
| 赃物处理 | 每次触摸赃物道具触发"赃物烫手"的红色闪烁 |

### 商店NPC系统
- **每个商店配置1-2个NPC店员**
- **店员反应系统**:
  - 胆小型: 抱头蹲下 → 概率偷偷按报警按钮(需要玩家注意到)
  - 勇敢型: 尖叫逃跑 → 吸引街道注意
  - 恐惧型: 心脏病触发 → 玩家面临"要不要叫救护车"的道德困境
    - 叫救护车: 增加被抓风险但救人一命(良心点数)
    - 不叫: 继续抢但NPC可能死亡(增加通缉等级)

### 环境随机事件
| 事件 | 概率 | 效果 |
|------|------|------|
| 顾客突然进店 | 15% | 需要决定: 赶走/无视/放弃抢劫 |
| 巡警经过店外 | 10% | 暂停动作, 心跳加速UI |
| 店内电话响 | 8% | 可能是店主家人/报警中心回拨 |
| 店员手机响 | 5% | 可能是家人, 触发道德抉择 |

## 5. 教育机制设计

### 核心设计哲学
**"不是不能犯罪，而是犯罪有重量"**

### 具体教育机制

1. **良心点数系统 (Conscience Points)**
   - 每次犯罪 -1 到 -5 点
   - 每次做善事(归还赃物/帮助NPC/自首) +1 到 +10 点
   - 良心点数低于阈值:
     - 出现"噩梦"系统消息(失眠效果)
     - NPC对话文本变化("你看起来很疲惫")
     - 商店购物价格略微上涨(形象影响)
   - 良心点数高:
     - NPC友善对话
     - 小概率获得隐藏任务线

2. **"犯罪日记"**
   - 每次抢劫后触发一个内心独白UI界面
   - 显示: "你拿到了 $X，但你知道这钱是偷来的"
   - 让玩家面对自己的选择

3. **正向引导路径**
   - 彻底放弃犯罪路线: 
     - 可找"职业顾问"NPC完成"改过自新"任务链
     - 完成后获得"第二人生"buff: 正经工作收入+20%
   - 赃物归还:
     - 匿名归还商店 → 商店老板会发感谢信(匿名)
     - 累计归还5次 → 解锁"宽恕者"称号

4. **警察追击的教育维度**
   - 被抓后不是简单的进监狱
   - 监狱里有"改造任务": 学习技能(编程/烹饪/手艺)
   - 刑满释放后有"前科记录": 部分工作拒绝雇佣
   - 但可以"改过自新": 完成社区服务任务清除记录

### 关键教育信息嵌入
```
不是不能扮演罪犯，而是要意识到——
  每个犯罪选择都有连锁反应。
  你在角色中体验后果，然后可以做出更好的选择。
  这就是角色扮演的意义：体验不同人生，然后选择你想成为的人。
```
