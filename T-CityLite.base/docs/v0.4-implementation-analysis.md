## 4. 架构亮点

### 4.1 单人模拟多人模式（Mock 引擎）

```typescript
// nui.ts 中的 Mock 在浏览器中完整模拟：
// - 4 个模拟联系人
// - 4 条模拟消息（含已读/未读）
// - 2 条模拟通知
// - 2 个 Job Board 任务（open + taken）
// - 3 个职业频道消息组（police, gang, civilian）
// - 2 条 CityFeed 帖子
// - 自动回复 2 秒后模拟
```

这是项目中**第一个**具备浏览器端完整 Mock 环境的资源，极大加速了 UI 开发。

### 4.2 离线转账 Rollback 机制

```lua
-- banking.lua 中的安全回滚：
-- 1. 扣减发送方金额
-- 2. 更新数据库
-- 3. 如果 DB 更新失败，自动回滚发送方金额
-- 这点是除 qb-banking 外唯一做了离线转账 + 回滚的系统
```

### 4.3 动态领袖 App 注册

```lua
-- client/main.lua 中的领袖 App 管理：
-- QBCore:Client:OnPlayerLoaded → CheckLeaderApp()
-- custom-career:client:tierChanged → CheckLeaderApp()
-- leader → registerLeaderApp（前端动态显示图标）
-- demote → removeLeaderApp（强制退出 App + 隐藏图标）
```
