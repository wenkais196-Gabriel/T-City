## 2. 向后兼容证明

| 保障机制 | 说明 |
|----------|------|
| **Legacy Shim** | `legacy_economy_shim.lua` 拦截 `Player.Functions.AddMoney`，当 `custom-main` 可用时自动路由到 `AddScaledMoney`，不可用则回退到原始实现 |
| **Compat Bus** | `compat.lua` 在 `[core]` 框架中提供相同的包装，输出 deprecation 日志但不中断流程 |
| **零 API 变更** | 所有旧接口 `QBCore.Functions.GetPlayer`、`Player.Functions.AddMoney` 语法完全不变 |
| **Service 前缀** | 新 Service export 以 `service_economy_` 前缀命名，不与旧 exports 冲突 |
| **逐步迁移** | 第三方插件可以逐文件迁移到新 Service，不迁移也正常运行 |

**结论**: 所有旧 Lua 脚本不改一行也能正常运行 ✅
