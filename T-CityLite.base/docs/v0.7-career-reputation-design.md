# T-City Lite — 职业声望与进阶养成系统设计

> **版本**: v0.7-draft  
> **状态**: 设计阶段  
> **依赖**: `core-framework`, `custom-career`, `players.metadata.rep`

---

## 1. 现状分析

### 1.1 已有声望 API

```lua
Player.Functions.AddRep('dealer', N)    -- 增加声望
Player.Functions.GetRep('dealer')       -- 查询声望 → number
```

存储位置：`players.metadata.rep = { dealer = 15, hotdog = 10, delivery = 5 }`

### 1.2 已有职业声望

| 声望 key | 来源 | 用途 |
|----------|------|------|
| `dealer` | 毒品送货 | dealer 商店 `minrep` 解锁进货品种 |
| `hotdog` | 卖热狗 | 仅累加，无解锁 |
| `delivery` | 商店配送 | 仅累加，无解锁 |

### 1.3 问题

1. **无统一等级体系** — 每个职业各自定义等级计算方式
2. **解锁纯硬编码** — dealer 的 `minrep` 是唯一解锁机制，其他职业无
3. **无 UI 反馈** — 除 dealer 外无进度条/等级显示
4. **不与 career 标签联动** — `custom-career` 的 `GetPlayerIdentity` 不知道声望
5. **无法跨职业** — 不支持一个玩家同时有多个职业声望

## 2. 架构设计

### 2.1 数据模型

```lua
-- players.metadata.rep 扩展为结构化声誉档案
rep = {
    -- 各职业声望值
    dealer      = 50,   -- 0~∞, 每 10 点 = 1 级
    police      = 120,
    medic       = 35,
    mechanic    = 80,

    -- 通用声誉（可与职业无关）
    overall     = 350,  -- 总经验
```

### 2.3 统一 API

```lua
-- CareerProgression API（注册到 Bus）
Bus.CareerProgression = {

    -- 获取当前等级
    GetLevel(source, careerName) → { level=5, rep=53, label='警长', nextLevelRep=60 }

    -- 检查是否解锁
    HasUnlock(source, careerName, unlockType, unlockId) → boolean

    -- 获取某职业已解锁的所有物品
    GetUnlocks(source, careerName) → { items={...}, weapons={...}, vehicles={...} }

    -- 增加声望（自动检查升级）
    AddRep(source, careerName, amount, reason) → { gained=5, newLevel=6, leveledUp=true }

    -- 注册自定义进阶（第三方模组）
    RegisterCareer(careerName, config) → boolean
}
```

### 2.4 等级计算公式

```
level = max(1, floor(sqrt(rep / TierScale)) + 1)
```

或更简单的线性：
```
level = floor(rep / TierScale) + 1
```

| rep | 等级 |
|-----|------|
| 0-9 | Lv.1 |
| 10-19 | Lv.2 |
| 20-29 | Lv.3 |
| 50-59 | Lv.6 |
| 100+ | Lv.11+ |

### 2.5 联动 custom-career

`CareerCache` 扩展为包含声望：

```lua
CareerCache[src] = {
    primary_role = 'police',
    rank_tier = 'mid',
    reputations = {
        police = { level = 5, rep = 53 },
        driver = { level = 2, rep = 15 },
    },
    unlocks = {
        weapons = { 'WEAPON_PISTOL', 'WEAPON_COMBATPISTOL' },
        vehicles = { 'police2' },
    },
}
```

`GetPlayerIdentity` 自动计算已解锁内容，`PlayerMatchesTags` 支持 `tier` 匹配。

### 2.6 跨职业声望

一个玩家可同时拥有多个职业声望：

```
玩家 A:
  dealer   Lv.8 (霸主)
  driver   Lv.3 (司机)
  mechanic Lv.1 (学徒)
```

切换职业不丢失之前声望——只是当前 `primary_role` 决定了哪个声望可用于解锁。

### 2.7 客户端进度条

复用 dealer 现有的 progress bar UI，抽象为通用组件：

```lua
-- 触发声望进度更新
TriggerClientEvent('career:client:updateRepBar', src, {
    career = 'dealer',
    level = 5,
    rep = 53,
    nextLevelRep = 60,
    label = '地下毒贩'
})
```

## 3. 解锁集成点

### 3.1 经销商商店

```lua
-- qb-drugs dealerShop 改造
local unlocks = exports['custom-career']:GetPlayerIdentity(source).unlocks
local availableItems = {}
for k, product in pairs(dealerData.products) do
    if unlocks.items[product.name] then
        availableItems[#availableItems+1] = product
    end
end
```

### 3.2 警察武器柜

```lua
-- 从 unlocks.weapons 读取
local unlocks = exports['custom-career']:GetPlayerIdentity(source)
-- 只显示已解锁武器
```

### 3.3 车库

```lua
-- qb-garages spawn 时检查 unlocks.vehicles
if unlocks.vehicles[vehicleModel] then
    -- 允许取出
```
