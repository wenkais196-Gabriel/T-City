## ⚡ 速查指令

```
/tccops [0-10]     — 临时调整抢劫警察门槛（0=随便抢，2=生产标准）
/selldrugs          — 切换街头毒品出售模式
/refreshdealers     — 刷新经销商交互区域（重启 qb-drugs 后执行一次）
/time HH MM        — 设置游戏时间
/weather TYPE      — 设置天气
/freezetime        — 冻结/解冻时间
/test run all      — 运行全部自动化测试套件
/test run 犯罪系统  — 运行犯罪系统测试（19 个用例）
/test run 安全边界  — 运行安全边界测试（17 个用例）
/stress            — 运行架构压力测试
/myid              — 查看自己的标识符
/giveitem [ID] [item] [amount] — 管理员给予物品

```

      □ 锁撬工具未被消耗
```

### 2.2 有警察时抢劫可触发

```
前置条件: 
  窗口1: 设置警察角色 /setjob [窗口1 ID] police 0 → /duty
  窗口2: 设置警察角色 /setjob [窗口2 ID] police 0 → /duty
  确保两个警察都在 duty 状态

操作（平民角色窗口）: 走到便利店收银台 → 使用锁撬工具
预期: 抢劫正常触发
验证: □ 锁撬小游戏界面弹出
      □ 破解成功后开始撬收银机动画（进度条）
      □ 收银机清空后获得 markedbills（标记纸币）和可能的小纸条
      □ 警方收到 "10-33 | Shop Robbery" 警报通知
