# T-City Lite v0.2 In-Game Test Checklist

本清单专为 **v0.2 基础 RP** 版本的实机测试设计，按功能模块划分子任务。您可以在游戏中依次进行测试，并勾选完成情况或在此记录测试遇到的报错。

---

## 📂 模块一：基础职业与管理 (`jobs.cfg`)

本模块核心验证 `progressbar`、`qb-management` 的加载与职业基础数据流。

- [x] **1.1 职业状态验证**
  - [x] 在游戏中输入管理员指令：`/setjob [自己的ID] police 1` 或 `/setjob [自己的ID] ambulance 1`。
  - [x] 观察客户端与服务端控制台是否报错，且屏幕提示是否成功。
  - [x] 验证角色属性（如 HUD 或侧边通知）是否正确更新为对应职业。

- [ ] **1.2 进度条（progressbar）底层验证**
  - [ ] 在执行需要进度条的动作（如使用急救包、搜身等）时，观察进度条 UI 是否正常弹出、文字是否匹配。
  - [ ] 进度条在倒计时结束时是否正常结束，以及在移动或按 ESC 时是否能成功打断。

- [ ] **1.3 boss 管理功能测试（qb-management）**
  - [ ] 作为对应职业的 boss 级别账号，尝试访问对应的 Boss 交互点（通常是对应职业更衣室或办公室的绿色/黄色标记）。
  - [ ] 打开 Boss 菜单（NUI），确认以下子功能可用：
    - [ ] 员工管理：尝试雇佣其他玩家、开除员工、修改员工的 Grade 薪资级数。
    - [ ] 账目管理：查看对应职业账目余额，测试存入资金（Deposit）与取出资金（Withdraw）。
  - [ ] **校验点**：操作后确认控制台无 SQL 错误，且职业资金在数据库中正确扣除/添加。

## 🏦 模块二：银行系统 (`banking.cfg`)

本模块核心验证 `qb-banking` 与数据库的联动及转账记录逻辑。

- [ ] **2.1 账户读取与基础 UI 唤起**
  - [ ] 前往任意银行网点或 ATM 机。
  - [ ] 靠近后按提示（例如按 `E` 键或通过 `qb-target` 交互）打开银行 UI。
  - [ ] 确认 UI 正常渲染，且能正确读取您的当前现金（Cash）与银行存款（Bank）余额。

- [ ] **2.2 存取款与转账操作**
  - [ ] **存款 (Deposit)**：输入一定金额并存入，确认钱包现金减少、银行存款增加。
  - [ ] **取款 (Withdraw)**：输入一定金额并取出，确认钱包现金增加、银行存款减少。
  - [ ] **转账 (Transfer)**：输入其他在线玩家的 CitizenID 或账号 ID 进行转账，验证双方的余额变化。
  - [ ] **校验点**：存取款操作后，打开数据库 `bank_accounts` 确认数值是否保持实时一致。

- [ ] **2.3 交易流水账单（Statements）验证**
  - [ ] 连续完成 2~3 笔存款/取款/转账交易。
  - [ ] 检查银行 UI 中的交易历史记录（Transactions），确认是否生成了对应的流水明细。
  - [ ] **校验点**：确认数据库 `bank_statements` 表中正常写入了包含时间戳和金额的记录。

## 🚗 模块三：车辆基础、钥匙与燃油 (`vehicles.cfg`)

本模块核心验证车钥匙分发、公共车库取存以及 LegacyFuel 的接口。

- [ ] **3.1 车辆生成与钥匙获取（qb-vehiclekeys）**
  - [ ] 使用管理员指令生成一辆测试载具（如 `/car taxi` 或 `/car panto`）。
  - [ ] 上车或靠近车辆后，确认角色能自动获得该载具的钥匙（屏幕应有提示：“You received the keys to this vehicle”）。
  - [ ] **锁车/解锁测试**：下车并靠近载具，按默认热键（通常是 `U` 键）进行锁车与解锁。
    - [ ] 确认锁车时有鸣笛/双闪提示，且尝试上车时车门已被锁死。
    - [ ] 确认解锁后能正常拉开车门并启动引擎。

- [ ] **3.2 车库（qb-garages）存取流测试**
  - [ ] 驾驶上述已获得钥匙的载具前往地图上的公共车库。
  - [ ] **存车测试**：靠近车库交互点，按提示存入该车辆。
    - [ ] 确认载具成功消失，且屏幕提示存车成功。
    - [ ] 检查数据库 `player_vehicles` 表，确认该载具的 `state` 字段是否更新为已存入（通常为 1 或 `stored`）。
  - [ ] **取车测试**：与车库管理员或交互标记对话，打开存车列表。
    - [ ] 确认列表中能看到您刚刚存入的载具。
    - [ ] 尝试取出载具，验证载具是否成功生成，且外观、车牌是否与之前一致。

- [ ] **3.3 燃油系统（qb-fuel）连通性验证**
  - [ ] 驾驶载具行驶一段距离，观察右下角 HUD 的燃油表是否正常消耗。
  - [ ] 前往任意加油站，停在加油机旁，测试通过交互（如 `E` 键或 `qb-target`）加油。
  - [ ] 确认加油时会扣除对应的金钱，且油箱重新加满。

## 👮 模块四：警察系统 (`police.cfg`)

本模块核心验证警察职业的 Duty 切换和基础执法交互。

- [x] **4.1 上下班状态切换 (Duty On/Off)**
  - [x] 前往警察局总署。
  - [x] 靠近值班点（或更衣室交互点），测试切换上班状态。
  - [x] **校验点**：
    - [x] 确认屏幕提示“You are now on duty”或“You are now off duty”。
    - [x] HUD 上的警员状态显示正确更新。
    - [x] 确认处于上班状态时才可使用以下后续交互。

- [ ] **4.2 警察互动菜单与执法动作**
  - [ ] 寻找一名在线的测试玩家（或测试假人），靠近并按交互菜单键。
  - [ ] 测试以下警察专属执法互动：
    - [ ] **搜身 (Search)**：尝试搜查该玩家的背包，确认可以正常查看其随身物品。
    - [ ] **戴手铐 (Cuff/Uncuff)**：对该玩家使用手铐，验证其角色动画是否变为戴手铐状态，且其行动受限。
    - [ ] **护送 (Escort)**：尝试抓取并护送该玩家，验证其是否跟随您的角色移动。
    - [ ] **扣押/车辆管理**：对路边载具进行扣押或车牌查询，确认逻辑能跑通。

## 🏥 模块五：医院与急救 (`medical.cfg`)

本模块核心验证倒地死亡惩罚、EMS 医疗救援与医院点位康复流。

- [x] **5.1 倒地死亡状态触发**
  - [x] 使用自伤手段（如高空跌落或管理员自残指令）使角色血量归零。
  - [x] 确认角色是否进入倒地/休克（Downed/Dead）动画，屏幕出现红色的倒计时提示（如等待 EMS 救援计时器）。
  - [x] 确认处于倒地状态下无法奔跑、打字或进行其他常规动作。

- [ ] **5.2 医疗康复与复活流 (Hospital Respawn)**
  - [ ] **方案 A：EMS 救援**：让另一名 EMS 玩家（或您切换到 EMS 职业）使用急救包或除颤器，对倒地玩家进行救治（Heal/Revive），验证倒地玩家是否能带着残余血量重新站起，且休克状态解除。
  - [ ] **方案 B：医院直接复活**：当倒计时结束后，按下提示键（如长按 `E` 键）请求在医院复活。
    - [ ] 验证角色是否成功被传送至医院（如 Pillbox 医院）的床位上，且血量部分恢复。
    - [ ] 确认扣除了对应的复活医疗费，并在银行流水中正确记录。

- [x] **5.3 退出重进状态保持（离线防逃避）**
  - [x] 使角色处于倒地休克状态，然后直接断开服务器连接（`/disconnect`）。
  - [x] 重新连接服务器并载入角色。
  - [x] **校验点**：载入后确认角色仍然保持倒地状态，无法通过退服重进的方式逃避死亡惩罚。
