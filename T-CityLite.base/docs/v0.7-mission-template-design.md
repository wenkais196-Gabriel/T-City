> **版本**: v0.7-draft  
> **状态**: 设计阶段  
> **复用**: 毒品送货 · 商店抢劫 · 房屋搜刮 · 银行劫案 · 珠宝劫案 · 卡车劫案

## 1. 现状：4 个独立实现的"同构"系统

| 系统 | 文件 | 核心循环 |
|------|------|---------|
| 毒品送货 | `qb-drugs/server/deliveries.lua` + `client/deliveries.lua` | 接单 → 取货 → 送货(限时) → 奖励+声望 |
| 毒品街头出售 | `qb-drugs/server/cornerselling.lua` + `client/cornerselling.lua` | 找NPC → 出售 → 概率被骗/被抢 → 奖励 |
| 商店抢劫 | `qb-storerobbery/server/main.lua` + `client/main.lua` | 撬锁 → 计时器(25s) → 警察检查 → 抢收银机/保险箱 |
| 房屋搜刮 | `qb-houserobbery/server/main.lua` + `client/main.lua` | 进屋 → 搜刮家具(并发锁) → 奖励 |

**共同模式**：

```
                    start          progress           complete
                    ─────          ────────           ────────
毒品送货:    Dealer → 给物品      → 倒计时+导航     → 送达/超时
毒品出售:    /selldrugs → 找NPC  → 动画+概率判定    → 成交/被骗
商店抢劫:    撬锁 → 警察检查     → 25s计时器        → 自动发奖
房屋搜刮:    进屋 → 无(可随时)    → 并发家具锁(30min) → 搜完
```

## 2. 通用模板抽象

```
┌──────────────────────────────────────────────────────────────┐
│                     MissionTemplate                         │
├──────────────────────────────────────────────────────────────┤
│  config:                                                     │
│    id = 'drug_delivery'       -- 唯一标识                   │
│    type = 'delivery'          -- delivery | robbery | sell   │
│    policeCheck = true         -- 是否需要警察检查            │
│    policeMin = 0              -- 最少需要多少警察            │
│    timeLimit = 300            -- 时间限制(秒), 0=无限制      │
│    cooldown = 0               -- 冷却时间(秒)               │
│                                                              │
│  hooks (服务端权威):                                         │
│    onStart(src) → bool, msg   -- 开始条件检查               │
│    onProgress(src, data)      -- 进度回调                   │
│    onComplete(src, data)      -- 完成回调(发奖)             │
│    onCancel(src, reason)      -- 取消/超时回调               │
│    onCleanup(src)             -- 清理回调                   │
│                                                              │
│  data: 模板自带的状态管理                                    │
│    active[sid] = { startTime, timeLeft, state, custom }     │
│    cooldowns[templateId] = { [cid]=timestamp }              │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 两种子类型

| 类型 | 流程 | 已有系统 |
|------|------|---------|
| **delivery** | NPC接单 → 给物品 → 导航到目标点 → 限时送达 → 奖励 | 毒品送货 |
| **robbery** | 触发(撬锁/爆破) → 警察检查 → 计时器 → 自动发奖 → 冷却 | 商店抢劫、房屋搜刮 |
| **sell** | 切换到销售模式 → 找NPC → 动画 → 服务器端概率判定 → 结果 | 街头出售 |

### 2.2 状态机

```
delivery:
  IDLE ──[accept]──→ ACCEPTED ──[items given]──→ EN_ROUTE
  EN_ROUTE ──[arrive+complete]──→ COMPLETED → IDLE
  EN_ROUTE ──[cancel/timeout]──→ CANCELLED → IDLE

robbery:
  IDLE ──[trigger+policeOK]──→ IN_PROGRESS ──[timer expires]──→ COMPLETED
  IN_PROGRESS ──[player left/arrested]──→ FAILED
  COMPLETED/FAILED ──[cooldown]──→ IDLE

sell:
  IDLE ──[toggle on]──→ SELLING ──[approach NPC]──→ NEGOTIATING
  NEGOTIATING ──[roll success]──→ SUCCESS (reward)
  NEGOTIATING ──[roll scam]──→ SCAMMED (lose items)
  NEGOTIATING ──[roll robbery]──→ ROBBED (lose items + chased)
```

### 2.3 统一 API

```lua
-- 注册到 Bus
Bus.MissionTemplate = {

    -- 注册新模板
    Register(config) → boolean

    -- 开始任务
    Start(source, templateId, customData) → boolean, errMsg

    -- 查询状态
    GetState(source, templateId) → { state, timeLeft, custom }

    -- 强制完成
    ForceComplete(source, templateId, result)

    -- 强制取消
    ForceCancel(source, templateId, reason)
}
```

## 3. 毒品送货 → 模板化示例

```lua
-- qb-drugs 改用模板后的配置
Bus.MissionTemplate.Register({
    id = 'drug_delivery',
    type = 'delivery',
    policeCheck = false,
    timeLimit = 300,
    cooldown = 0,

    onStart = function(src)
        local Player = QBCore.Functions.GetPlayer(src)
        -- 检查是否已有进行中的送货
        -- 检查声望是否满足
        return true
    end,

    onAccept = function(src, data)
        -- 随机生成送货内容
        data.item = RandomDeliveryItemOnRep()
        data.amount = math.random(1, 3)
        data.location = Config.DeliveryLocations[math.random(#Config.DeliveryLocations)]
        -- 给玩家物品
        exports['qb-inventory']:AddItem(src, data.item, data.amount)
        -- 发送GPS短信
        TriggerClientEvent('phone:client:gpsMessage', src, {
            message = '送货任务...',
            gps = data.location.coords,
            status = 'active'
        })
    end,

    onComplete = function(src, data)
        -- 检查物品 + 发奖
        local Player = QBCore.Functions.GetPlayer(src)
        Player.Functions.AddMoney('cash', data.payout)
        Player.Functions.AddRep('dealer', 1)
    end,

    onCancel = function(src, reason)
        -- 回收物品? 还是保留作为惩罚?
        QBCore.Functions.Notify(src, '送货已取消')
    end,
})
```

## 4. 商店抢劫 → 模板化示例

```lua
Bus.MissionTemplate.Register({
    id = 'store_robbery',
    type = 'robbery',
    policeCheck = true,
    policeMin = 2,
    timeLimit = 25,           -- 25秒计时器
    cooldown = 1800,          -- 30分钟冷却

    onStart = function(src, storeId)
        -- 检查冷却 + 警察人数
        local Player = QBCore.Functions.GetPlayer(src)
        local cops = QBCore.Functions.GetDutyCount('police')
        if cops < 2 then return false, '需要至少2名执勤警察' end
        -- 检查商店冷却
        if storeCooldowns[storeId] then
            return false, '这家店刚被抢过'
        end
        return true
    end,

    onComplete = function(src, data)
        -- 25秒计时器到 → 自动发奖
        local Player = QBCore.Functions.GetPlayer(src)
        local reward = math.random(250, 450)
        Player.Functions.AddMoney('cash', reward)
        exports['qb-inventory']:AddItem(src, 'markedbills', 1, false, {worth=reward})
        -- 设置冷却
        storeCooldowns[data.storeId] = os.time()
    end,

    onProgress = function(src, data)
        local elapsed = os.time() - data.startTime
        local remaining = 25 - elapsed
        -- 通知客户端更新计时器
        TriggerClientEvent('store-robbery:client:updateTimer', src, remaining)
    end,
})
```

## 5. 可复用的场景

| 场景 | 类型 | 特殊逻辑 |
|------|------|---------|
| 🚚 毒品送货 | delivery | 声望解锁不同货品 |
| 🍕 披萨外卖 | delivery | 无警察风险，固定奖励 |
| 📦 快递配送 | delivery | 多段路线（取→中转→送） |
| 🏪 商店抢劫 | robbery | 警察门槛 + 收银机/保险箱 |
| 🏦 银行劫案 | robbery | 多阶段（爆破→钻金库→逃跑） |
| 💎 珠宝劫案 | robbery | 展示柜逐个打破 |
| 🏠 房屋搜刮 | robbery | 并发家具锁 |
| 🚛 卡车劫案 | robbery | 移动目标 + 警察追捕 |
| 💰 运钞车 | robbery | 跟踪→拦截→爆破 |
| 💊 街头出售 | sell | 概率判定 + NPC反应 |
