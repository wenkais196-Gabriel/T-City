## 4. 本次验收中修复的测试问题

1. `Test.skip` 使用 `error(msg, 0)`，使“玩家未加载”被正确计为 SKIP，而不是 ERROR。
2. `custom-testing` 引入 `@oxmysql/lib/MySQL.lua`，手机套件的建表检查可用。
3. 手机套件改用 `QBCore.ServerCallbacks[name]` 校验 callback 注册（QBCore 服务端没有 `GetCallback`）。
4. 犯罪套件的经济出口断言从已移除的 `custom-economy:AddScaledMoney` 改为 `core_economy:TriggerReward` / `GetGlobalMultiplier`。
