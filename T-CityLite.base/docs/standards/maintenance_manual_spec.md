## 1. 维护手册的核心目的

单人开发与 Agent 运维环境下，维护手册致力于消除信息盲区。当发生全服重启、数据异常或偶发性 BUG 时，运营方能够通过检索文档在 **3分钟内** 完成故障定位与灾难恢复。

## 3. 排错指南编写准则 (Troubleshooting Principles)

> [!CAUTION]
> 绝对不要编写毫无建设性的排错说明（如“如果报错，请重装服务器”）。

排错手册应提供**精准的诊断条件与命令**，例：
*   **不良排错描述**：若手机时间不准，检查是不是脚本死锁。
*   **优秀排错描述**：若手机时间卡在 `12:00`，请在 F8 键入 `/checktime`，若返回 `worldTime: frozen`，请用 `/unfreezeworld` 恢复全服时间状态。
