## 🧪 测试场景 A: 非法组织线 — Cartel 从入门到洗钱

### A1. 创建测试角色
```
F8 控制台:
  /setjob 1 miner 0        (先设个临时身份)
  /setgang 1 cartel 0      (加入 cartel，等级 Halcon)
```

### A2. 组织仓库验证
```
1. /orgstoragelist          (管理员查看所有组织仓库配置)
   预期: 列出 miner 150格、cartel 80格、police 80格 等

2. /cartelstorage           (打开 cartel 仓库)
   预期: 打开80格库存界面，标题显示 "Cartel 安全屋"

3. /orgstorage               (自动检测组织并打开)
   预期: 非 cartel 玩家执行时打开对应组织仓库
```

### A3. 交易市场验证
```
1. /market                   (查看全部商品行情)
   预期: 22种商品列表，显示价格/供需/涨跌

2. /market ores              (查看矿石分类)
   预期: 铁/铜/金/银/煤/石 6种矿石行情

3. /marketsetprice cocaine 150   (管理员手动调价)
   预期: 可卡因价格变为 $150

4. 通过分销商出售 5 个 cocaine
   预期: 价格 >= $100/个，入账 bank，市场供给增加
```

### A4. 毒品生产链验证
```
1. 移动到 Madrazo Ranch (1310, 1120, 103)
2. /cartellab                (打开实验室菜单)
   预期: 显示 3 个配方 (古柯膏/可卡因/大麻包装)

3. 找化学供应商 NPC 购买原料:
   古柯叶 $10/个、硫酸 $25/个、丙酮 $30/个

4. 选择 "古柯膏" 配方 → progressbar 30秒
   预期: 消耗 3 coca_leaf + 1 sulfuric_acid → 1 coca_paste

5. /cartelmembers            (查看在线成员)
   预期: 列出所有 cartel 在线成员及等级
```

### A5. 洗钱管道验证
```
1. 拥有 $10,000 cash
2. 使用 /cartellab 找到分销商 NPC 批量出售毒品
   或通过脚本直接调用:
   F8: TriggerServerEvent('cartel:server:sellToDealer', 'cartel_drug_dealer', 'cocaine', 5)

3. 使用当铺洗钱 (已有 LaunderMoney):
   预期: 75% 保留率，cartel 成员 +5% = 80%
```

## 🧪 测试场景 B: 合法组织线 — 矿业公司从采矿到交易

### B1. 创建矿业角色
```
  /setjob 1 miner 0          (加入矿业公司，等级 学徒)
  /giveitem 1 pickaxe 1      (给予矿镐)
```

### B2. 采矿流程验证
```
1. /mine                     (查看矿点列表)
   预期: 列出 4 个矿点 (砂石场/山区/沙漠/海岸)

2. 前往砂石场 (-595, 3492, 30)
   预期: 地图上有 ⛏️ Blip，进入范围显示 qb-target "在砂石场采矿"

3. 按 E 开始采矿
   预期: progressbar 循环，每次 ~5秒
   预期: 产出铁矿石/铜矿石/石料 (权重随机)
   预期提示: "⛏️ 获得 铁矿石 → 组织仓库"

4. 换高级矿镐测试
   /giveitem 1 pickaxe_pro 1
   预期: 采集速度加快30%，15%概率双倍产出
```

### B3. 冶炼流程验证
```
1. 前往冶炼厂 (1080, -1980, 30)
   预期: 地图上有 🔥 Blip，显示 qb-target "冶炼矿石"

2. 打开冶炼菜单 → 选择 "冶炼铁锭"
   预期: 原料 3 iron_ore + 1 coal → 1 iron_ingot (15秒)

3. 检查组织仓库: /orgstorage
   预期: 铁锭已存入 miner 仓库 (150格)
```

### B4. 市场交易验证
```
1. /market ores              (查看矿石行情)
2. /market ingots            (查看金属锭行情)
   预期: 矿产价格因采矿活动而波动
```

## 🧪 测试场景 C: 司法生态闭环

### C1. 准备角色
```
玩家A: /setjob 1 police 4    (警察 — Chief)
玩家B: /setjob 2 lawyer 4    (律师 — Managing Partner)
玩家C: /setjob 3 judge 4     (法官 — Chief Justice)
玩家D: 任意平民
```

### C2. 逮捕流程
```
1. 玩家A (警察) 对玩家D:
   /arrest [玩家D的ID] assault,drug_possess
   预期: 
   - 警察: "案件 CASE-0001 已登记"
   - 嫌疑人: "你已被逮捕！指控: 故意伤害, 持有毒品 | 基础刑期: 45分钟"
   - 律师 (玩家B): 📋 新案件通知

2. 玩家B (律师):
   /cases                     (查看待审案件)
   预期: 显示 CASE-0001 | 嫌疑人 | 待接案
```

### C3. 律师接案 + 审判
```
1. 玩家B (律师):
   触发 "接受案件" 选项 (通过 arrest.lua 事件)
   预期: 嫌疑人收到通知 "律师 xxx 已接受你的案件"

2. 玩家C (法官):
   /cases                     (查看案件)
   对 CASE-0001 开庭
   预期: 判决 45分钟 - 律师减刑13分钟 - 初犯减免9分钟 = 23分钟

3. 玩家D (嫌疑人):
   预期: 收到判决通知 → 传送到监狱 → 开始计时
```

### C4. 监狱管理
```
1. 玩家D 在监狱中按 E:
   预期: 弹出菜单 "良好表现减刑" (减15%)
   申请后: 23分钟 → 约20分钟

2. 玩家A (警察) 或 玩家C (法官):
   /inmates                   (查看在押囚犯)
   预期: 列表显示囚犯信息和剩余刑期

3. 等待计时结束:
   预期: 自动出狱 → 传送到监狱外 → 通知 "你已出狱"
```

## 🛠️ 全部可用命令速查表

### 玩家命令

| 命令 | 系统 | 权限 | 说明 |
|------|------|------|------|
| `/gangstorage` | Storage | 帮派成员 | 打开帮派仓库 (显示组织名+帮派名+等级) |
| `/jobstorage` | Storage | 所有人 | 打开职业仓库 (显示职业名+等级) |
| `/market [分类]` | Market | 所有人 | 查看市场行情 |
| `/cartellab` | Cartel | cartel成员 | 打开毒品实验室 |
| `/cartelstorage` | Cartel | cartel成员 | 打开cartel仓库 |
| `/cartelmembers` | Cartel | cartel成员 | 查看在线成员 |
| `/mine` | Mining | 所有人 | 查看矿点列表 |
| `/arrest [ID] [罪名]` | Justice | 警察 | 逮捕并登记案件 |
| `/cases` | Justice | 法官/律师 | 查看待审案件 |
| `/inmates` | Justice | 警察/法官 | 查看在押囚犯 |

### 管理员命令

| 命令 | 系统 | 说明 |
|------|------|------|
| `/orgstoragelist` | Storage | 列出所有组织仓库配置 |
| `/marketsetprice [物品] [价格]` | Market | 手动设定商品价格 |
| `/cartelinfo` | Cartel | Cartel 全局状态(成员/raid风险) |
| `/careertest` | Career | 多标签+许可证桥接测试 |

### 开发调试命令

| 命令 | 来源 | 说明 |
|------|------|------|
| `/setjob [ID] [job] [grade]` | qb-core | 设置玩家职业 |
| `/setgang [ID] [gang] [grade]` | qb-core | 设置玩家帮派 |
| `/giveitem [ID] [item] [count]` | qb-adminmenu | 给予物品 |
| `/reloadquests` | custom-quest | 热重载任务配置 |
| `/tpgates` | cartel-gates | 传送到cartel大门 (调试) |
| `/gatedebug` | cartel-gates | 3D门锁调试信息 |
