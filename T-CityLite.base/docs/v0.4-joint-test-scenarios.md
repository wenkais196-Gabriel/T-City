## 🧪 测试情景 1：手机基础功能

### 1.1 手机开关
```
操作: 按 M 键
预期: 手机从底部滑入，显示主屏幕（App 图标网格）
验证: □ 手机动画流畅无卡顿
      □ 主屏幕显示 10 个 App 图标（短信/联系人/银行/通知/Job Board/职业频道/CityFeed/通话/车库/热线）
      □ 顶部状态栏显示时间、信号

操作: 再次按 M 键
预期: 手机滑出，回到游戏画面
验证: □ 手机完全消失
      □ 游戏操作恢复正常（鼠标/移动/攻击）
```

### 1.2 手机外壳
```
操作: 打开手机，观察 UI
预期: 手机有真实感外壳（刘海/边框/状态栏）
验证: □ 手机外壳视觉完整
      □ 下滑手势或点击空白区域无法关闭手机（必须按 M）
```

## 🧪 测试情景 2：短信系统

### 2.1 发送消息
```
操作: 点开短信 App → 新建消息 → 输入自己的号码 → 发 "你好"
预期: 消息显示在对话中
验证: □ 消息显示已发送（右侧气泡）
      □ 服务端打印 [custom-phone] sendMessage 日志
```

### 2.2 接收消息（需要双开或另一个玩家）
```
操作: 用另一个 FiveM 窗口（或请朋友）发消息给你
预期: 即使手机未打开，也收到通知弹窗
验证: □ 游戏右上角弹出 "💬 New Message" 通知
      □ 打开短信 App 看到新消息（左侧气泡）
      □ 消息旁有已读/未读标记
```

### 2.3 安全校验
```
操作: 发送超过 500 字的消息
预期: 消息被拒绝
验证: □ 提示 "Message must be between 1 and 500 characters"
```
