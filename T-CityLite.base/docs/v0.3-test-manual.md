## 🛠️ 测试准备与前置环境 (Prerequisites)

1. **测试服务器环境**：确认 `server.cfg` 中以下配置已启用并加载了全部自定义子资源：
   ```cfg
   exec configs/modules/custom.cfg
   ```
2. **测试账号与权限**：测试账号具备游戏内管理员权限，钱包内初始持有现金 `$10,000`，银行 Checking 账户有 `$5,000` 存款。
3. **数据库连接**：确认 `QBCore_CDB34E` 数据库运行正常，且 `bank_statements` 联合索引 `idx_citizenid_account_date` 已建立，`players` 表连接良好。

## 🏦 测试集 1：银行系统柜台金融重构与对账一致性测试 (`qb-banking`)

### 🧪 用例 1.1：柜员对账一致性与备注测试
* **目的**：验证基本存取款功能的正常计算与对账历史写入。
* **操作步骤**：
  1. 走近 Maze Bank 柜台交互点，按 `E` 唤起柜台菜单。
  2. 观察右上角 `Pocket Cash` 显示的金额，确认是否与背包中的现金一致。
  3. 输入金额 `$1,000` 并选择 **Checking Deposit** (存款)，备注输入 `Deposit_Test_001`，点击确认。
  4. 输入金额 `$500` 并选择 **Checking Withdraw** (取款)，备注输入 `Withdraw_Test_002`，点击确认。
  5. 翻阅底部的 `TRANSACTION STATEMENTS`。
* **预期结果**：
  - 存款后，`Pocket Cash` 变为 `$9,000`，账户余额变为 `$6,000`。
  - 流水中生成带绿色向上箭头的记录 `+$1,000`，备注字样为 `Deposit_Test_001`。
  - 取款后，`Pocket Cash` 变为 `$9,500`，账户余额降为 `$5,500`。
  - 流水中生成带红色向下箭头的记录 `-$500`，备注字样为 `Withdraw_Test_002`。
  - 登录数据库，执行：
    ```sql
    SELECT * FROM bank_statements WHERE citizenid = '<Your CID>' ORDER BY id DESC LIMIT 2;
    ```
    确认这两条备注已以正负值与明文备注完美存盘。

### 🧪 用例 1.2：共享子账户开户、存取、销户退款闭环
* **目的**：验证子账户（Shared）的开户、流水归属和销户原路全额退款。
* **操作步骤**：
  1. 在左侧面板的 `Create New Account` 中输入账户名 `Beta-Shared`。
  2. 设置类型为 `Shared`，初始存入金额输入 `$2,000`，点击开户。
  3. 点击左侧新生成的 `Beta-Shared` 卡片，观察其余额及流水。
  4. 切换回 Checking 卡片，观察其余额。
  5. 切换到 `Beta-Shared`，存款 `$500`（备注：`In`），取出 `$200`（备注：`Out`）。
  6. 进入 `Access Control` 面板，滑动到最下方 `Danger Zone`，点击 **Close Account & Refund** 按钮。
  7. 重新点击 Checking 账户卡片，查看其余额及流水记录。
* **预期结果**：
  - Checking 余额扣减 `$2,000`；`Beta-Shared` 产生，初始余额为 `$2,000`。
  - `Beta-Shared` 的交易流水仅有一条开户初始流入：`+$2,000` (Initial deposit)。
  - 存取款后子账户余额更新为 `$2,300`，流水记录正确写入两笔明细。
  - 销户退款点击后，`Beta-Shared` 彻底从侧边栏注销并清除。
  - Checking 余额立即增加 `$2,300`；Checking 交易流水单中新增一条备注为 `Refund from closure of Beta-Shared` 的 `+$2,300` 存款对账记录。

### 🧪 用例 1.3：子账户重名开户“幽灵数据”防漏测试 (关键高危漏洞验证)
* **目的**：验证已被销户并清退余额的子账户在不重启服务器的情况下，重名创建不会复活历史脏流水。
* **前提条件**：完成 **用例 1.2**，且**切勿重启服务器**。
* **操作步骤**：
  1. 保持在线，在 `Create New Account` 中输入**完全重名**的账户名：`Beta-Shared`。
  2. 设置为 `Shared` 账户，初始存入金额输入 `$100`，点击开户。
  3. 点击新生成的 `Beta-Shared`，检查其余额及下方交易流水。
* **预期结果**：
  - 开户成功，余额显示为 `$100`。
  - 下方的流水列表中，**只展示一条**当前开户的 `+$100` (Initial deposit) 流水。
  - 用例 1.2 中所产生的任何旧流水（如 `$2,000`, `$500`, `-$200`）**均未出现，幽灵流水判定清理率 100%**。
